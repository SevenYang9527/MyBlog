后处理

内置渲染管线使用的 Post-Processing Stack v2 包与 URP 不兼容。

URP 不需要额外的包来产生后处理（post-processing）效果，而是改用 Volume 框架（Volume framework）。当你在场景中添加 Volume 时，可以选择哪些后处理效果应用于该 Volume。Volume 可以是 Global（全局）或 Local（局部）。如果设为 Global，该 Volume 会影响场景中任意位置的摄像机。

当 Mode 设置为 Local 时，只有当摄像机位于 Collider 的边界之内时，Volume 才会影响该摄像机。

使用 URP 后处理框架

  1. 第一步是确保你的 Main Camera 启用了后处理。在 Hierarchy 窗口中选择 Main Camera，进入 Inspector，展开 Rendering 面板，勾选 Post Processing 选项。

  2. 在 Hierarchy 窗口中右键单击，选择 Create > Volume > Global Volume，创建一个全局 Volume。

  3. 在 Hierarchy 窗口中选中该 Global Volume，在 Inspector 中找到 Volume 面板，单击 New 创建一个新的 Profile。

  4. 开始添加后处理效果。请参阅下方列出可用效果的表格。单击 Add Override 并选择 Post-processing。在本例中选择了泛光（Bloom）效果。

  1. 每个效果都有专用的 Settings 面板。这里的图像展示了泛光的设置。

  1. 你可以轻松添加多个效果（例如本例中的暗角），并使用各自的 Settings 面板配置每一个效果。

添加局部 Volume

借助 Volume 框架，你可以配置场景，使摄像机移动时触发不同的后处理 Profile。这通过添加局部 Volume（Local Volume）来实现。下面我们来逐步完成设置。

  1. 在 Hierarchy 窗口中右键单击，选择 Create > Volume > Box Volume。或者，如果 Sphere Volume 更符合你的用途，也可以选择它；如果你希望对定义 Volume 区域的 Collider 形状进行更精细的控制，则选择 Convex Mesh Volume。

  2. 在 Inspector 的 Volume 面板中，创建新的 Profile 来存储该 Volume 数据。该面板还可用于设置：

    1. Blend Distance：这是 URP 开始混合时距 Volume 的 Collider 的最远距离，也是该 Profile 在 Collider 尺寸范围内淡入的距离。在 Collider 边缘处，后处理效果会淡出；而在距 Collider 边缘 Blend Distance 的距离处，效果会完全淡入。

    2. Weight：Weight 定义后处理效果的最大强度。如果 Weight 设为 1，效果将达到完整强度。设为 0 表示没有效果，而 0.5 则将效果强度上限设为 50%。

    3. Priority：当多个 Volume 对场景的影响相同时，用该值决定 URP 使用哪个 Volume。数值越大，Priority 越高。如果你同时混用 Global 和 Local，请将 Global 保持默认值 0，并把 Local Volume 设为 1 或更高。

  1. 使用 Box Collider 组件调整 Volume 的位置并控制其尺寸，如下图所示。

后处理会给处理器带来较大负担，因此在低端硬件和移动设备上要仔细考虑其影响。如果你的项目必须使用后处理，请在目标硬件上进行测试。有些滤镜对处理器的消耗低于其他滤镜。本文档概述了对移动设备友好的效果。

以下是 URP 中可用的后处理效果。

效果 说明
Bloom 在高于指定亮度的像素周围添加光晕。
Channel Mixer 修改每个输入颜色通道对整体混合的影响。
Chromatic Aberration 沿分隔图像明暗部分的边界产生彩色边纹。
Color Adjustments 使用该效果微调最终渲染图像的整体色调、亮度和对比度。
Color Curves 分级曲线（grading curves）是一种调整色相、饱和度或亮度中特定范围的高级方法。
Color Lookup 使用查找纹理（Lookup Texture）将每个像素的颜色映射到新的值。
Depth of Field 该效果模拟摄像机镜头的对焦特性。
Film Grain 模拟摄影胶片的随机光学纹理。
Lens Distortion 扭曲最终渲染画面，以模拟真实世界摄像机镜头的形状。
Lift Gamma Gain 使用不同的轨迹球影响图像中的不同范围。调整轨迹球下方的滑块可偏移该范围的色彩亮度。
Motion Blur 模拟真实世界摄像机拍摄运动速度快于摄像机曝光时间的物体时图像中出现的模糊。
Panini Projection 该效果帮助你在视野非常大的场景中渲染透视视图。
Shadows Midtones Highlights 该效果分别控制渲染的阴影、中间调和高光。
Split Toning 用它为场景中的阴影和高光添加不同的色调。
Tonemapping 色调映射（tonemapping）是将图像的 HDR 值重映射到新值范围的过程。
Vignette 该效果使图像边缘相对中心变暗。
White Balance 消除不真实的色偏，使现实生活中的白色物体在最终图像中渲染为白色。

用代码控制后处理

你也可以使用 C# 脚本动态调整后处理 Profile。下面的代码示例展示了如何调整泛光效果强度。如果应用了暗角，你可以通过代码控制暗角颜色。例如，当玩家角色受到伤害时，你可以临时将其染成红色。

using UnityEngine;
using UnityEngine.Rendering;
using UnityEngine.Rendering.Universal;

public class PPController : MonoBehaviour
{
    // Start 在第一帧更新之前被调用
    void Start()
    {
        Volume volume = GetComponent<Volume>();
        Bloom bloom;

        if (volume.profile.TryGet<Bloom>(out bloom))
        {
            bloom.intensity.value = 0;
        }
    }
}
