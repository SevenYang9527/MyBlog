管线回调（Pipeline callbacks）

SRP 的一大优势是：你可以借助 C# 脚本，在渲染流程几乎任意阶段插入代码。可注入脚本的阶段包括：

  • 渲染阴影
  • 渲染预通道（prepass）
  • 渲染 G-buffer
  • 渲染延迟光照（Deferred lights）
  • 渲染不透明物体（opaques）
  • 渲染天空盒（Skybox）
  • 渲染透明物体（transparents）
  • 渲染后处理（post-processing）

你可以通过 Universal Renderer Data Asset 的 Inspector 中的 Add Renderer Feature 选项，把脚本注入渲染流程。请记住，使用 URP 时存在 Universal Renderer Data 对象和 URP Asset 两个资产。URP Asset 拥有一个 Renderer List，其中至少分配了一个 Universal Renderer Data 对象。这个资产需要在 Project Settings > Graphics > Scriptable Render Pipeline Settings 中指定。

如果你正在为不同场景试验多套设置资产，那么把下面的脚本挂到 Main Camera 上会很有用。在 Inspector 中设置 Pipeline Asset，之后它就会在新场景加载时切换资产。

using UnityEngine;
using UnityEngine.Rendering;
using UnityEngine.Rendering.Universal;

[ExecuteAlways]
public class AutoLoadPipelineAsset : MonoBehaviour
{
    public UniversalRenderPipelineAsset pipelineAsset;

    // Start 在第一帧更新前被调用
    void OnEnable()
    {
        if (pipelineAsset)
        {
            GraphicsSettings.renderPipelineAsset = pipelineAsset;
        }
    }
}

下一节将介绍两种不同类型的 Renderer Feature，一种面向美术人员，另一种面向有经验的程序员。

Render Objects

游戏中的一个常见问题是：玩家角色躲到环境物体后面时，玩家会看不见角色。你可以尝试移动摄像机，让角色始终在视野内，或者把环境调整得尽可能开阔。但这些方案并不总是可行。一个不错的技巧是：当有环境模型出现在角色与摄像机之间时，显示角色的剪影（silhouette），如下图所示。

下面是创建这个剪影的方法：

  1. 首先，你需要一个在角色被遮挡时使用的材质。新建一个材质，把 Shader 设为 Universal Render Pipeline > Lit 或 Unlit（上一张图展示的是 Lit 选项）。设置 Surface Inputs > Base Map 的颜色。在本例中，该材质名为 Character。
  2. 为了避免不必要地多次渲染角色，我们把它放到一个专用层上。选中角色，在 Layers 列表中添加一个 SeeBehind 层，并为角色选中该层。
  3. 选中 URP Asset 所使用的 Renderer Data 对象。转到 Opaque Layer Mask，排除 SeeBehind 层。此时角色就会消失。
  4. 点击 Add Renderer Feature，选择 Render Objects (Experimental)。
  5. 填写这个 Render Object 的 Pass 设置。为它命名，并选择渲染应在何时触发。在本例中，它名为 AfterRenderingOpaques。
  6. 此时，只有当角色位于另一个物体之后时，你才能看到它的剪影；当角色完全可见时，你根本看不到它。要解决这个问题，请再添加一个 Render Objects 功能。这一次不需要改动 Overrides 面板。这个 Pass 会在角色未被其他物体遮挡时绘制角色。

把 Layer Mask 设为 SeeBehind 层，也就是为角色选择的那个层。展开 Overrides，把 Override Mode 设为 Material。选择第 1 步创建的材质。渲染时你会希望使用深度信息，但不希望通过写入深度缓冲来更新它。把 Depth Test 设为 Greater，这样该 Pass 只在被渲染像素到摄像机的距离大于深度缓冲中当前存储的距离时才渲染。

Renderer Feature

Renderer Feature 可以在 URP 的任意阶段使用，以影响最终渲染结果。我们来走一遍添加后处理效果的简单示例。在使用内置渲染管线（Built-in Render Pipeline）的项目中，你必须通过 OnRenderImage 回调来调用 Graphics.Blit。本示例使用的是该函数的一个变体，它带有一个材质，用于逐像素处理图像。

  1. 先在项目 Assets 文件夹中找到一个合适的文件夹。右键选择 Create > Rendering > URP Renderer Feature，命名为 TintFeature。
  2. 双击默认的 TintFeature 文件。它是一个 C# 脚本，包含 Renderer Feature 的样板代码。

剪影技巧很好地展示了如何利用 URP 工作流来添加那些在内置渲染管线工作流中因依赖编码而难以实现的效果。

  1. 把 CustomRenderPass 重命名为 TintPass，并向 CustomRenderPass 类添加下列属性。材质将包含你要应用到当前渲染图像状态上的 Shader。
  2. 为 TintPass 添加一个构造函数以初始化材质，并设置该 Pass 在渲染管线中的位置。
  3. 添加一个 SetTarget 方法，用于初始化 TintPass 类的 cameraColorTarget 和 color 属性。
  4. 新建一个 Shader，命名为 TintBlit，然后复制下面的代码。注意其中的 RenderPipeline 标签。ZWrite 和 Cull 均为关闭状态。Core.hlsl 从 com.unity.render-pipelines.universal 导入，Blit.hlsl 从 com.unity.render-pipelines.core 导入。如果你在 URP Asset Inspector 中选中 Opaque Texture，那么管线会创建一个 Render Texture，即 _CameraOpaqueTexture。
public TintPass(Material mat)
{
    material = mat;
    renderPassEvent = RenderPassEvent.BeforeRenderingPostProcessing;
}
public void SetTarget(RTHandle colorHandle, Color col)
{
    cameraColorTarget = colorHandle;
    color = col;
}

Material material;
RTHandle cameraColorTarget;
Color color;
  1. 用下列属性替换 CustomRenderPass m_ScriptablePass。你可以在 Renderer Data 资产的 Inspector 中设置 Shader 和 Color。
public Shader shader;
public Color color;
Material material;
TintPass renderPass = null;
Shader "Custom/TintBlit"
{
    SubShader
    {
        Tags { "RenderType"="Opaque" "RenderPipeline" = "UniversalPipeline"}
        LOD 100
        ZWrite Off Cull Off
        Pass
        {
            Name "TintBlitPass"
            HLSLPROGRAM
            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            // Blit.hlsl 文件提供了顶点着色器（Vert）、
            // 输入结构（Attributes）和输出结构（Varyings）
            #include "Packages/com.unity.render-pipelines.core/Runtime/Utilities/Blit.hlsl"

            #pragma vertex Vert
            #pragma fragment frag

            TEXTURE2D(_CameraOpaqueTexture);
            SAMPLER(sampler_CameraOpaqueTexture);

            float4 _Color;

            half4 frag (Varyings input) : SV_Target
            {
                float4 color = SAMPLE_TEXTURE2D(_CameraOpaqueTexture, sampler_CameraOpaqueTexture, input.texcoord);
                return color * _Color;
            }
            ENDHLSL
        }
    }
}

该 Shader 对它进行采样，并用 _Color 值对其进行调制。
