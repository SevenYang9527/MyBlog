转换流程

本节介绍使用 URP 新建项目，或将现有项目转换为 URP 的具体步骤。

如何打开一个新的 URP 项目

通过 Unity Hub 使用 URP 打开一个新项目。点击 New，确认窗口顶部所选的 Unity 版本为 2022.2 或更高版本。为项目指定名称和位置，选择 3D (URP) 模板或 3D Sample Scene (URP)，然后点击 Create。

注意：该模板会确保项目使用线性颜色空间（linear color space），这是正确计算光照所必需的。

你可以通过 File > New Scene 创建新场景，其中包含 Camera 和 Directional light 等基本 GameObject，甚至可以用预先填充的对象创建自己的场景模板。更多内容请参阅 URP Scene Templates 文档。

转到 Edit > Project Settings，打开 Graphics 面板。要在编辑器内使用 URP，你必须在 Scriptable Render Pipeline Settings 中选择一个 URP Asset。URP Asset 控制项目的全局渲染与质量（Quality）设置，并创建渲染管线实例。而渲染管线实例则包含中间资源和渲染管线的具体实现。

默认选中的 URP Asset 是 UniversalRP-HighFidelity，但你可以切换到 UniversalRP-Balanced 或 UniversalRP-Performant。

本指南稍后的章节会详细介绍如何调整 URP Asset 的各项设置。

如何向现有的内置渲染管线（Built-in Render Pipeline）项目添加 URP

重要：在执行本节步骤之前，务必使用版本控制系统备份项目。此过程会转换资源，而 Unity 不提供撤销选项。如果你使用了版本控制，则可以在需要时回退到资源的先前版本。

如果要升级现有的内置渲染管线项目，你需要自行将 URP 包添加到项目中，因为 Unity 2022.2 或 2022 LTS 并未内置该包。

转到 Window > Package Manager，点击 Packages 下拉菜单，将 URP 添加到项目中。确保选择 Unity Registry，然后选择 Universal RP。如果开发计算机上尚未安装 URP 包，请点击窗口右下角的 Download。下载完成后点击 Install。

要创建 URP Asset，在 Project 窗口中右键单击，选择 Create > Rendering > URP Asset (with Universal Renderer)。为该资源命名。

请记住：如果你使用 Universal Render Pipeline 或 3D (URP) 模板创建新项目，这些 URP Asset 以及 URP 包已经存在于项目中。

URP 并不创建单个 URP Asset，而是使用两个文件，二者都以 Asset 为扩展名。

其中一个称为 UniversalRP_Renderer，是一个 Renderer Data Asset，你可以用它筛选渲染器所作用的层，并拦截渲染管线以自定义场景的渲染方式。通过这种方式，你可以更方便地创建高质量效果。更多信息请参阅「管线回调」（Pipeline callbacks）一节。

此外，UniversalRP_Renderer 还控制 URP 的高层渲染逻辑与各个 Pass。它支持前向（Forward）和延迟（Deferred）路径，以及一个 2D 渲染器，后者可启用 2D 光源、2D 阴影和光源混合样式（Light Blend Styles）等功能。你甚至可以扩展 URP 来创建自己的渲染器。

另一个 URP Asset 用于控制质量（Quality）、光照（Lighting）、阴影（Shadows）和后处理（Post-processing）等设置。你可以使用不同的 URP Asset 来控制质量设置，本节稍后会概述这一流程。该设置资源（Settings Asset）通过 Renderer List 与渲染器数据资源（Renderer Data Asset）相链接。创建新的 URP Asset 时，设置资源会拥有一个仅含单个条目的 Renderer List——即同时创建的那个渲染器数据资源，并被设为默认值。你可以向此列表添加其他渲染器数据资源。

默认渲染器用于所有摄像机（Camera），包括场景视图（Scene view）。摄像机可以通过从 Renderer List 中选择另一个渲染器来覆盖默认渲染器。如有需要，也可以通过脚本实现这一点。

尽管已按上述步骤创建了 URP Asset，场景视图或游戏视图中打开的场景仍会使用内置渲染管线。你还必须完成最后一步才能切换到 URP：转到 Edit > Project Settings，打开 Graphics 面板。点击 None (Render Pipeline Asset) 旁边的小圆点，在打开的面板中选择 UniversalRP。

此时会弹出关于此次切换的警告信息，直接点击 Continue 即可。

由于项目中还没有任何内容，更改渲染管线几乎是瞬间完成的。现在你已准备好使用 URP 了。

转换现有项目的场景

完成上述步骤后，你会发现原本精美的场景突然变成了洋红色。这是因为内置渲染管线项目中材质所使用的着色器不受 URP 支持。幸运的是，有一种方法可以让场景恢复到原本的质量。

转到 Window > Rendering > Render Pipeline Converter。2D 项目选择 Convert Built-In to 2D (URP)，3D 项目选择 Built-In to URP。假定你的项目是 3D 项目，则需要选择相应的转换器：

  • Rendering Settings：选择此项会创建多个渲染管线设置资源，尽可能匹配内置渲染管线的质量设置。这样你就能更高效地测试不同的质量级别。更多细节请参阅「比较内置渲染管线与 URP 的质量选项」一节。
  • Material Upgrade：用它把材质从内置渲染管线转换为 URP。
  • Animation Clip Converter：用于转换动画剪辑。它在 Material Upgrade 转换器完成后运行。
  • Read-only Material Converter：用于转换 Unity 项目中包含的预制只读材质。它会为项目建立索引并创建临时 .index 文件。注意，这可能耗时较长。

转换自定义着色器

自定义着色器不会通过 Material Upgrade 转换器进行转换。「Shaders」和「New tools」两节概述了将自定义内置渲染管线着色器转换为 URP 的步骤。使用 Shader Graph 通常是将自定义着色器更新到 URP 的最快方式。

URP 提供了若干不同的着色器，包括：

  • Universal Render Pipeline/Lit：这个基于物理的渲染（PBR）着色器类似于内置的 Standard Shader，可用于表现大多数真实材质。它支持 Standard Shader 的所有功能，并同时支持金属（metallic）和镜面反射（specular）工作流。
  • Universal Render Pipeline/Simple Lit：使用 Blinn-Phong 模型，适合低端移动设备或不使用 PBR 工作流的游戏。
  • Universal Render Pipeline/Unlit：这是一个对 GPU 性能友好的着色器，不使用光照方程。
  • Universal Render Pipeline/Terrain/Lit：适合与 Terrain Tools 包配合使用。
  • Universal Render Pipeline/Particles/Lit：这个粒子着色器使用 PBR 光照模型。
  • Universal Render Pipeline/Particles/Unlit：这个无光照粒子着色器对 GPU 的负担很小。

尽管 Simple Lit 可以替代许多旧版/移动端着色器，但性能并不相同。旧版/移动端着色器只对光照进行部分计算，而 Simple Lit 会按照 URP Asset 的定义考虑所有光源。

请参阅 URP 文档中的这张表格，了解每个 URP 着色器与其内置渲染管线对应项的映射关系。

选择一个或多个上述转换器后，点击 Initialize Converters 或 Initialize And Convert。无论选择哪一种，项目都会被扫描，需要转换的资源会被添加到各个转换器面板中。如果选择 Initialize Converters，你可以通过取消勾选每个条目提供的复选框来限制转换范围。在此阶段，点击 Convert Assets 开始转换过程。如果选择 Initialize And Convert，则在转换器初始化完成后会自动开始转换。转换完成后，系统可能会要求你重新打开编辑器中当前活跃的场景。

比较内置渲染管线与 URP 的质量选项

内置渲染管线提供了若干默认质量选项，从 Very low 到 Ultra 不等。质量设置会影响场景的保真度，包括纹理分辨率、光照、阴影渲染等。

转到 Edit > Project Settings，选择 Quality 面板。在这里，你可以通过选择当前质量级别在这些质量选项之间切换。这会改变场景视图和游戏视图所使用的渲染设置。你也可以在此面板中编辑每一个质量选项。

如果在使用 Render Pipeline Converter 从内置渲染管线切换到 URP 时选择了 Rendering Settings 选项，系统会创建一组 URP Asset，尽量匹配内置渲染管线的质量选项。下面的第一张表展示了 Low 设置下内置渲染管线与 URP 的对应关系，第二张表则展示了 High 设置的对比。在内置渲染管线和 URP 中，设置都通过 Quality 面板选择。选中 URP Asset 时，可以在 Inspector 中查看 URP Asset 的设置。更多细节请参阅 URP 文档。
