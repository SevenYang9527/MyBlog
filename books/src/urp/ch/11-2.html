1. 点击「+」按钮，并添加一个 Color 属性。这样用户就可以在 Inspector 中调整烟雾（smoke）的颜色。
  2. 来看一下 Spawn 块。默认的 Spawn 块自带一个 Constant Spawn Rate 节点。把它设为 20。
  3. 下一个块是 Initialize，它定义了粒子（particle）在首次创建时如何处理。移除 Set Lifetime Random 节点。然后添加一个 Set Tex Index，并将其设为一个 0 到 63 之间的随机值，这样每个烟雾粒子都会有不同的外观。这一点很重要，因为粒子显示的是前面展示过的 Smoke Sprite 图集中的一张图像，而你会希望使用的第一个索引为 0。

    然后添加一个 Set Lifetime 节点，设为 1.5 秒。为了给粒子的发射速度增加一些变化，使用 Set Velocity Random 节点。把 A 设为 -0.1, 0.4, -0.1，把 B 设为 0.1, 1, 0.1。要把粒子的 Color 设置为提亮或压暗 Sprite，添加一个 Set Color 节点，并把创建的 Color 属性拖到它的输入上。

  4. 下一个块是 Update，它定义了每一帧更新时发生的事情。默认情况下，它显示为一个空块，但实际上它包含了一些隐式的隐藏块，当选中 Update 时可以在 Inspector 中禁用它们。

    回想一下，你正在为每个粒子的图像使用一张 Sprite 图集。在 VFX Graph 中，这意味着你在使用一个翻页书（Flipbook）。添加一个 Flipbook Player 节点，把它的 Mode 设为 Constant，把 Frame Rate 设为 16。它将以每秒 16 次的帧切换速度循环播放 Flipbook 中连续的帧。

  5. 接下来，设置粒子的最终输出。把 UV Mode 设为 Flipbook（若想让帧与帧之间的过渡更平滑，则设为 Flipbook Blend），把 Flipbook Layout 设为 Texture 2D。使用该 Sprite 图集，把 Flipbook Size 设为 8x8，并把 Main Texture 设为这张 Texture。用 Set Alpha Over Life 替换 Set Color Over Life。默认的曲线会让粒子在其生命周期内淡入并淡出。
  6. 选中挂载了这个 VFX Graph 的 GameObject。在 Scene 视图中，应该会看到一个面板，你可以用它来在运行之外演示该效果。如果你没有看到它，请确认用于可视化 Particle Systems 的开关已打开。

2D 渲染器与 2D 光照（2D Renderer and 2D lights）

如果你正在开发一款 2D 游戏，你会很高兴地得知 URP 有一个专用的 2D 渲染器（2D Renderer）。最简单的上手方式是从 Unity Hub 中使用 2D URP 模板（template）。该模板可确保你的项目通过 Project Settings > Graphics > Scriptable Render Pipeline Settings 指定了一个 URP 2D Renderer。所有经过验证并已预编译的 2D 包都会随 2D URP 模板一起安装，并且默认设置已针对 2D 项目进行了优化。这还能确保项目比手动安装所有包时加载得更快。

如果你是在升级一个现有项目，那么需要在项目的 Assets 文件夹中找一个合适的文件夹。右键单击并选择 Create > Rendering > URP Asset (with 2D Renderer)。给它起个名字，然后通过 Project Settings > Graphics > Scriptable Render Pipeline Settings 选中它。在 Scene 视图中编辑时，务必选中 2D 按钮。

如果你是在更新一个现有项目，那么你可能会发现切换到 URP 2D Renderer 后出现了经典的洋红色渲染错误。

URP 中可用的 2D 着色器（shader）

Shader Description
Sprite-Lit-Default 渲染时使用 2D 光照
Sprite-Mask-Default 与模板缓冲区（stencil buffer）配合工作
Sprite-Unlit-Default 渲染时只使用纹理的颜色

幸运的是，Window > Rendering > Render Pipeline Converter 已经为你考虑到了这一点。选择 Built-in to 2D (URP)，然后单击 Material and Material Reference Upgrade 面板。接着单击 Initialize Converters，随后单击 Convert Assets，以便能够取消选择某些项目；或者单击 Initialize And Convert，一键完成整个流程。如果你仍然看到洋红色的 Sprite，可能需要手动替换某些材质中的 shader。请从下表中挑选一个 shader。

URP 2D Renderer 提供了 2D 光照。这些光照带来了更高的性能和灵活性。使用这些新工具，你可以创造更具沉浸感的体验，并通过使用烘焙光照（baked light）来创造新的玩法可能性，从而省去准备不同 Sprite 变体的时间。如果你迁移了一个现有项目，那么场景中不会有任何 URP 2D 光照。如果你的 Sprite 使用了 Sprite-Lit-Default shader，你可能会惊讶地看到一个受光照的渲染结果。但在没有光照的情况下，场景会被分配一个默认的全局光照（Global Light），从而呈现出无光照（unlit）的外观。

通过 Hierarchy 窗口添加一个光照。右键单击并选择 Light > Global Light 2D。

现在你可以调整 Settings、Color、Intensity，以及它们所影响的 Target Sorting Layers（排序图层）。

2D URP 框架包含四种光照类型：

  • Sprite：使用一个 Sprite 来控制照明强度。
  • Freeform：用于创建多边形形状的光照。
  • Spot：对所选光照的角度和方向提供极佳的控制。可以把它当作点光源（Point light）使用。默认情况下，内锥角和外锥角都覆盖 360 度。你还可以调整内半径和外半径，并决定该光照是否投射阴影，以及阴影的强度。
  • Global：照亮目标排序图层上的所有对象。

如果某个 Sprite 要投射阴影，那么需要为它添加一个 Shadow Caster 2D 组件。

URP 2D Renderer 提供了创建一流 2D 游戏所需的全部工具，即使在低端硬件上也能表现出色。
