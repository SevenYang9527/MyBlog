第 8 章 原神：Ramp 分层、MatCap 与 SDF 面部阴影

原神在碧蓝幻想的基础上又往前走了一步：材质不再靠一个固定的 Ramp，而是把 Ramp 做成一张分层图集；高光、阴影、视角光都从 LightMap 的不同通道里取；脸不再依赖编辑法线，而是用 SDF（Signed Distance Field）生成干净的阴影边界。

这套做法的好处是“一套 Shader 覆盖大量角色”，代价是数据通道变多、生成工具变复杂。原笔记把原神的数据拆成 LightMap 四个通道加顶点色两个通道，基本可以当成一张“角色材质协议”。

Ramp 图集：10 层，白天/黑夜各一半

原神的 Ramp 不是一条 1D 渐变，而是一张 256×20 的图集：横向是光照值，纵向是 10 层材质，每层再分白天/黑夜两半。运行时先由 LightMap.a 选出层，再由昼夜/场景状态决定采样上半还是下半。原笔记给的映射是：Layer 0.0~0.1 用第 6 行，0.11~0.33 用第 2 行，0.34~0.55 用第 3 行，0.56~0.9 用第 4 行，0.95~1.0 用外部传入的 _RampIndex。

float layer = SAMPLE_TEXTURE2D(_LightMap, sampler_LightMap, uv).a;
float rampIndex = _RampIndex;

if (layer <= 0.10) rampIndex = 6;
else if (layer <= 0.33) rampIndex = 2;
else if (layer <= 0.55) rampIndex = 3;
else if (layer <= 0.90) rampIndex = 4;

float u = saturate(halfLambert + rampOffset);
float v = (rampIndex * 2.0 - 1.0) / 20.0;
float3 rampColor = SAMPLE_TEXTURE2D(_RampTex, sampler_RampTex, float2(u, v)).rgb;

SDF 面部阴影

原神的脸没有走“编辑法线”这条路，而是用一张 SDF 贴图记录“当前像素到阴影边界的距离”。运行时把光照方向转到头部/模型空间，算出一个角度，再把角度映射成阈值，去和 SDF 比较，得到干净的明暗边界。角色转头时，只要更新光照方向，阴影就会在脸上平滑地移动。

原笔记的 SDF 生成流程比较长：先把脸的黑白阴影图做 8ssdet（8-points Signed Sequential Euclidean Distance Transform），得到每个像素到边界的距离；再把 15 张关键帧 SDF 按权重融合，得到“转头过程”的连续 SDF；最后做模糊和 Shader 端抗锯齿。这样做的原因是：单张 SDF 只能表达一个角度，15 张融合后才能覆盖左右转头。

// 光照方向转到局部空间，算水平角
float3 localLight = mul(unity_WorldToObject, float4(lightDirWS, 0)).xyz;
float angle = atan2(localLight.x, localLight.z) * (180.0 / PI) + 180.0;
float threshold = angle < 180.0
                ? smoothstep(0.0, 180.0, angle) * 0.99
                : smoothstep(360.0, 180.0, angle) * 0.99;

// 超过 180° 时镜像 UV，保证左右脸都能采到
float flip = angle > 180.0;
float2 faceUV = flip ? float2(1.0 - uv.x, uv.y) : uv;
float sdf = SAMPLE_TEXTURE2D(_FaceSDF, sampler_FaceSDF, faceUV).r;
float faceLight = step(threshold, sdf);

MatCap 与后处理边缘光

原神的“视角光”大量使用 MatCap：把法线转到视角空间，取 XY 去采样一张球形光照图，就能得到随视角变化的亮斑。它比实时算 N·L 更可控，尤其适合金属饰片、头发和眼睛。

后处理边缘光也在原神里出现：先单独渲染人物 Mask，再对深度图做邻域采样，深度差超过阈值的像素判为轮廓，最后只给人物加边缘光。原笔记提到只检测左右两个像素也能得到差不多效果，用 RimPixelOffset 控制采样偏移。

float3 normalVS = mul((float3x3)UNITY_MATRIX_V, normalWS);
float2 matcapUV = normalVS.xy * 0.5 + 0.5;
float3 matcap = SAMPLE_TEXTURE2D(_MatCapTex, sampler_MatCapTex, matcapUV).rgb;

// 后处理：深度差 + 人物 Mask
float center = LinearEyeDepth(SAMPLE_DEPTH_TEXTURE(_CameraDepthTexture, uv), _ZBufferParams);
float side = LinearEyeDepth(
    SAMPLE_DEPTH_TEXTURE(_CameraDepthTexture, uv + float2(_RimPixelOffset, 0)), _ZBufferParams);
float rim = step(_DepthThreshold, abs(center - side)) * characterMask;
数据原神里的用途Unity 落地
LightMap.r高光类型层按区间选高光分支
LightMap.g阴影 AO压暗常暗区域
LightMap.b高光强度乘到高光项
LightMap.aRamp 层选 Ramp 图集行
VertexColor.gRamp 偏移加到 halfLambert
VertexColor.a描边宽度乘到 Outline 外扩

Unity 视角：SDF 贴图不要按普通颜色贴图导入：关闭 sRGB、关闭压缩或使用高质量压缩、Filter 设为 Bilinear，否则边缘会出现色带。光照方向一定要转到角色/头部空间再算角度，否则角色转身时阴影会“跳”。如果项目没有 15 张关键帧，至少也要准备左、中、右三张，否则转头范围一大就会穿帮。

本章要点：原神把 Ramp 做成图集、把高光/阴影/描边拆进 LightMap 通道，再用 SDF 解决脸部阴影。SDF 的关键不是采样，而是生成：距离场、多角度融合、模糊、抗锯齿，一步都不能少。
