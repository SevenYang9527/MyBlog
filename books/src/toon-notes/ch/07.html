第 7 章 碧蓝幻想：11 层材质与组合式 NPR

《碧蓝幻想》和《罪恶装备》同属 ARC System Works，基础做法一致：UV 竖直展开、平滑法线、LightMap 存偏移、顶点色存 AO、贴花独立 Mesh。差别在于碧蓝幻想的角色更“插画化”，一个角色身上的材质类型更多，于是它把材质层做到了 11 层，并把“每层有哪些特性”做成了可组合的开关。

层信息存在 BaseMap 的 Alpha 通道里：0~1 被切成 11 段，每段代表一种材质。运行时先采样 BaseMap.a，判断当前像素落在哪一层，再从该层读取 Rim、高光、视角光、两层明暗等开关。

固定分层 vs 组合式分层

原笔记对比了两种设计。固定分层是给每个层写死一套 Shader 逻辑，层与层之间互不影响；组合式分层是把“两层明暗、Rim、高光、裁边高光、视角光”做成开关，每层自由勾选。前者简单、可预测；后者灵活，但分支更多，材质面板也更复杂。

NprData：把“一层”变成结构体

原笔记用一个 NprData 结构体承载每层参数：是否两层明暗、是否有 Rim、是否有高光、是否有裁边高光、是否有视角光，以及 Base、Shadow、Ramp、遮罩、高光指数等贴图与标量。光照函数只读这个结构体，不再关心“现在处理的是第几层”。

struct NprData
{
    bool  hasTwoLayerShadow;
    bool  hasRim;
    bool  hasSpecular;
    bool  hasStepSpecular;
    bool  hasViewLight;

    float3 baseColor;
    float3 shadowColor;
    float3 rimColor;
    float3 specColor;

    float  rampOffset;
    float  shadowMask;
    float  specMask;
    float  rimWidth;
    float  rimExp;
    float  specExp;
};

下面的伪代码把常见分支串起来。实际工程里通常不会真的用 bool 分支，而是用 uint flags、关键字或预乘遮罩，减少片元着色器的动态分支。

float3 NprLighting(NprData d, float3 N, float3 L, float3 V)
{
    float ndl = dot(N, L);
    float halfLambert = ndl * 0.5 + 0.5;

    float bright = step(_LightThreshold,
                        halfLambert + d.rampOffset * _RampOffsetMask) * d.shadowMask;
    float3 color = lerp(d.shadowColor, d.baseColor, bright);

    if (d.hasRim)
    {
        float rim = 1.0 - saturate(dot(N, V));
        rim = step(1.0 - d.rimWidth, rim);
        color += d.rimColor * rim;
    }

    if (d.hasSpecular)
    {
        float3 H = normalize(L + V);
        float spec = pow(saturate(dot(N, H)), d.specExp);
        spec = step(_SpecThreshold, spec) * d.specMask;
        color += d.specColor * spec;
    }

    return color;
}

金属的“暗边”

碧蓝幻想的金属不是靠一张环境贴图，而是靠 Fresnel 把边缘压暗：Diffuse *= pow(1 - saturate(N·V), exp) * intensity。这和常见的“边缘提亮”相反，但在卡通金属上很好用——边缘变暗，中间的色块更亮，金属的厚度感就出来了。

设计点碧蓝幻想的做法Unity 对应
材质分层BaseMap.a 切 11 段采样 Alpha，映射到 layer index
特性开关每层勾选 Rim/高光/视角光Keyword、uint flags 或预乘遮罩
金属Fresnel 压暗 Diffusepow(1 - N·V, exp)
边缘光类型StepNV / StepNL / StepNH用不同向量做 step，按层选择
头发/脸/描边与罪恶装备基本一致可复用同一套 Pass

Unity 视角：组合式材质最容易失控的是变体数量。Shader Graph 里每加一个 Boolean Keyword，材质变体就翻一倍；更稳的做法是用一张 LayerMap 加一个 uint 位掩码，把常用组合压成少量关键字。移动端尤其要限制“每层都开一堆分支”的做法。

本章要点：碧蓝幻想的核心是“层 + 特性开关”：11 层材质、组合式 NPR、Fresnel 金属暗边、多种 Rim 类型。它比罪恶装备更灵活，但也更依赖工程约束。
