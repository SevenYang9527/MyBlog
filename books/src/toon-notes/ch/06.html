第 6 章 罪恶装备 Strive：LightMap 的三个通道

《罪恶装备 Strive》是这套笔记里最重要的案例：它用 3D 模型做出了接近 2D 动画的观感。模型面数在五万面级别，很多信息不再靠材质参数，而是塞进贴图和顶点色里，让一套 Shader 能覆盖大量角色部件。

原笔记把它的数据拆得很细，核心是两张表：一张 LightMap，一张顶点色。LightMap 的 R/G/B 分别管材质类型、Ramp 偏移、高光类型；顶点色的 R/G/B/A 分别管阴影 AO、脸/发切换、无用通道、描边宽度。理解这两张表，比记某个阈值有用得多。

为什么要把 UV 竖着排

原笔记提到罪恶装备的 UV 是竖直展开的，贴图也按竖向条带组织。这样做的好处是：同一类部件可以共用一条 Ramp/LightMap 采样带，减少贴图切换；同时也方便美术把“哪些地方更容易感光”画进 G 通道。它不是为了省 UV 空间，而是为了让数据布局服务于 Shader 的采样方式。

脸与头发共用材质

原笔记提到，罪恶装备的脸和头发使用同一个材质，用顶点色的 G 通道来区分：G 大于 0.5 走脸部逻辑，否则走头发逻辑。脸部阴影不是纯 N·L，而是先由美术在 DCC 里编辑法线，让鼻子、颧骨、下巴附近的法线朝向更适合“动画脸”的方向；运行时仍然用同一套漫反射，但阴影形状已经被法线“画”过了。

头发则额外需要高光遮罩和暗部高光控制。原笔记的头发高光用 HairSpecularIntensityMask * BaseMap * lerp(HairDarkIntensity, HairBrightIntensity, ...) 这类组合，让高光在亮部出现、在暗部按需要保留或消失。

float layer      = SAMPLE_TEXTURE2D(_LightMap, sampler_LightMap, uv).r;
float rampOffset = SAMPLE_TEXTURE2D(_LightMap, sampler_LightMap, uv).g;
float specType   = SAMPLE_TEXTURE2D(_LightMap, sampler_LightMap, uv).b;

float shadowAO  = i.color.r;
float isFace    = step(0.5, i.color.g);
float outlineA  = i.color.a;

float ndl = dot(normalWS, lightDirWS);
float halfLambert = ndl * 0.5 + 0.5;
float bright = step(_LightThreshold,
                    halfLambert + rampOffset + _RampOffsetMask) * shadowAO;

float3 diffuse = lerp(shadowColor, baseColor, bright);
float3 faceDiffuse = lerp(faceShadowColor, baseColor, bright);
diffuse = lerp(diffuse, faceDiffuse, isFace);

贴花与自发光

罪恶装备的贴花不是画在基础贴图上的，而是用单独的 Mesh 加一张贴花图，再用 clip 或透明混合把没有图案的地方裁掉。这样做有两个好处：贴花可以独立控制分辨率，不会因为基础贴图压缩而糊；不规则的图案也不会在 UV 接缝处产生锯齿。自发光同样是单独 Mesh，不参与主光照。

数据通道作用
LightMap.rR材质/高光类型：普通、皮革、金属
LightMap.gGRamp 偏移：让某些区域更容易感光
LightMap.bB高光强度或高光类型
顶点色.rRShadowAO：常暗区域
顶点色.gG脸/发切换
顶点色.aA描边宽度

Unity 视角：在 URP 里复刻这套做法，不需要真的做 11 层材质。先把 LightMap 的 R/G/B 采样出来，用 if/step 做分支；顶点色通过 COLOR 语义传入。要注意移动端的分支成本：能在贴图里预乘的，就不要在片元里做太多 if。另外，编辑法线要在导入模型时保留自定义法线，不要让 Unity 重新计算。

本章要点：罪恶装备的核心不是复杂 BRDF，而是数据布局：LightMap 管材质/偏移/高光，顶点色管 AO/脸发/描边。脸用编辑法线，贴花和自发光用独立 Mesh。
