动画（Animation）

Unity 的 Mecanim 系统相当完善。如果可能，请借助后文介绍的设置来限制它在移动端上的使用。

使用通用骨骼而非人形骨骼（Generic versus humanoid rigs）

默认情况下，Unity 以通用骨骼（Generic Rig）导入带动画的模型，但开发者在对角色制作动画时常常会切换到人形骨骼（Humanoid Rig）。人形骨骼比等效的通用骨骼多消耗 30–50% 的 CPU 时间，因为它每一帧都会计算反向运动学（inverse kinematics）和动画重定向（animation retargeting），即使这些功能并未被使用也是如此。如果你不需要人形骨骼的这些特定功能，请改用通用骨骼。

Animator 的开销可能很高。

避免过度使用 Animator（Avoid excessive use of Animators）

Animator 主要面向人形角色，但也常被用来驱动单个数值（例如 UI 元素的 alpha 通道）。请避免过度使用 Animator，尤其是在与 UI 元素结合使用时。在移动端上，只要有可能，就应改用旧版 Animation 组件（legacy Animation components）。对于简单的动画（例如 DOTween），可以考虑自行编写补间函数（tweening functions）或使用第三方库。
