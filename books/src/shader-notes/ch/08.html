基础纹理：单张纹理、法线贴图、渐变与遮罩

原书第 7 章把纹理分成四类：单张纹理、凹凸映射（高度纹理/法线纹理）、渐变纹理、遮罩纹理。它们看起来都是“采样一张图”，但背后解决的问题不同：颜色、表面细节、风格化色调、以及按通道控制效果。

单张纹理

Properties
{
    _MainTex ("Texture", 2D) = "white" {}
    _Color ("Tint", Color) = (1,1,1,1)
}

sampler2D _MainTex;
float4 _MainTex_ST;
fixed4 _Color;

v2f vert (appdata v)
{
    v2f o;
    o.pos = UnityObjectToClipPos(v.vertex);
    o.uv = TRANSFORM_TEX(v.uv, _MainTex);
    return o;
}

fixed4 frag (v2f i) : SV_Target
{
    return tex2D(_MainTex, i.uv) * _Color;
}

纹理导入设置会影响结果：Wrap Mode（Repeat/Clamp）、Filter Mode（Point/Bilinear/Trilinear）、sRGB、压缩、Mipmap。UI 和像素风通常用 Point + Clamp；3D 表面常用 Bilinear + Repeat。

凹凸映射：高度纹理与法线纹理

高度纹理存“高度”，法线纹理存“法线方向”。实时渲染更常用法线纹理：它直接给出切线空间法线，片元阶段用 UnpackNormal 解包，再和光照方向计算。

sampler2D _BumpMap;
float4 _BumpMap_ST;
float _BumpScale;

struct v2f
{
    float4 pos : SV_POSITION;
    float2 uv : TEXCOORD0;
    float3 worldNormal : TEXCOORD1;
    float3 worldPos : TEXCOORD2;
    float3 tangent : TEXCOORD3;
    float3 bitangent : TEXCOORD4;
};

fixed4 frag (v2f i) : SV_Target
{
    float3 normal = UnpackNormal(tex2D(_BumpMap, i.uv));
    normal.xy *= _BumpScale;
    normal.z = sqrt(1.0 - saturate(dot(normal.xy, normal.xy)));

    float3 N = normalize(
        i.tangent * normal.x +
        i.bitangent * normal.y +
        i.worldNormal * normal.z
    );

    // 用 N 参与光照计算...
    return fixed4(N * 0.5 + 0.5, 1.0);
}

法线纹理通常有两类：切线空间（Tangent Space）和模型空间（Object Space）。切线空间法线贴图可以复用在不同模型上，更常见；模型空间法线贴图适合特殊风格或不需要变形的物体。

渐变纹理

渐变纹理把光照结果映射到一条颜色带上，常用于卡通/风格化渲染。做法是用 Lambert/Half-Lambert 得到一个 0~1 的值，再用它采样一张 1D 渐变纹理：

sampler2D _RampTex;
float _RampOffset;

float halfLambert = dot(N, L) * 0.5 + 0.5;
float3 rampColor = tex2D(_RampTex, float2(halfLambert + _RampOffset, 0.5)).rgb;
float3 diffuse = _LightColor0.rgb * _DiffuseColor.rgb * rampColor;

渐变纹理的 Wrap Mode 通常设为 Clamp，避免采样到边缘外的颜色。

遮罩纹理

遮罩纹理用通道控制不同效果：R 通道控制高光强度、G 通道控制自发光、B 通道控制某些细节。它比在 Shader 里写很多 if 更灵活，也更适合美术调整。

sampler2D _MaskTex;

fixed4 frag (v2f i) : SV_Target
{
    fixed4 mask = tex2D(_MaskTex, i.uv);
    float specMask = mask.r;
    float emissionMask = mask.g;

    float3 specular = _LightColor0.rgb * _SpecularColor.rgb
                    * pow(saturate(dot(N, H)), _Gloss) * specMask;
    float3 emission = _EmissionColor.rgb * emissionMask;

    return fixed4(diffuse + specular + emission, 1.0);
}

纹理采样的常见坑

  • UV 没做 ST 变换：Tiling/Offset 不生效，或者和材质面板不一致。
  • 法线贴图没解包：直接把 0~1 的纹理值当法线，光照会明显不对。
  • 切线空间基向量没归一化/正交化：法线贴图方向会偏。
  • 纹理 sRGB/Linear 设置不对：颜色发灰/过亮，尤其是线性空间项目。
  • 压缩伪影：法线贴图用错压缩格式，边缘会出现块状噪声。

现代 Unity 备注：URP 里法线贴图同样用切线空间，但解包函数/宏可能不同；UnpackNormalScale 可以同时处理缩放。纹理的 sRGB、压缩、Mipmap 设置比 Shader 代码更容易被忽略，排查时先看导入设置。

本章要点：单张纹理解决颜色；法线纹理解决表面细节；渐变纹理解决风格化色调；遮罩纹理用通道控制效果。纹理的 ST、解包、切线空间、sRGB/压缩设置，决定了“代码对了但画面不对”的大部分问题。
