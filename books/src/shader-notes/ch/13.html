屏幕后处理：把整帧当成一张图

原书第 12 章讲屏幕后处理（Post-Processing）。思路是：场景先渲染到一张 RenderTexture，再用一个全屏 Pass 对这张图做颜色调整、边缘检测、模糊、Bloom、运动模糊，最后输出到屏幕。它把 Shader 从“物体表面”扩展到了“整帧图像”。

最基本的后处理脚本

using UnityEngine;

[ExecuteAlways]
[RequireComponent(typeof(Camera))]
public class PostEffect : MonoBehaviour
{
    public Shader shader;
    Material material;

    Material Material
    {
        get
        {
            if (material == null)
                material = new Material(shader) { hideFlags = HideFlags.HideAndDontSave };
            return material;
        }
    }

    void OnRenderImage(RenderTexture src, RenderTexture dest)
    {
        if (Material != null)
            Graphics.Blit(src, dest, Material);
        else
            Graphics.Blit(src, dest);
    }

    void OnDisable()
    {
        if (material != null)
            DestroyImmediate(material);
    }
}

Shader 只需要一个全屏顶点/片元 Pass，片元里用 i.uv 采样 _MainTex。Unity 会提供全屏四边形。

亮度、饱和度、对比度

float _Brightness;
float _Saturation;
float _Contrast;

fixed4 frag (v2f i) : SV_Target
{
    fixed4 color = tex2D(_MainTex, i.uv);
    color.rgb *= _Brightness;

    float luminance = dot(color.rgb, float3(0.2126, 0.7152, 0.0722));
    color.rgb = lerp(luminance.xxx, color.rgb, _Saturation);

    color.rgb = (color.rgb - 0.5) * _Contrast + 0.5;
    return color;
}

边缘检测

边缘检测用卷积核对邻域像素做加权求和，常用 Sobel 算子。核心是把亮度/颜色梯度变成边缘强度：

float luminance(float3 c) { return dot(c, float3(0.2126, 0.7152, 0.0722)); }

float4 frag (v2f i) : SV_Target
{
    float2 texel = _MainTex_TexelSize.xy;
    float l = luminance(tex2D(_MainTex, i.uv + float2(-texel.x, 0)).rgb);
    float r = luminance(tex2D(_MainTex, i.uv + float2( texel.x, 0)).rgb);
    float b = luminance(tex2D(_MainTex, i.uv + float2(0, -texel.y)).rgb);
    float t = luminance(tex2D(_MainTex, i.uv + float2(0,  texel.y)).rgb);

    float edge = abs(l - r) + abs(b - t);
    return lerp(_BackgroundColor, _EdgeColor, saturate(edge));
}

高斯模糊

高斯模糊通常拆成水平/垂直两 Pass，降低采样数。权重按高斯分布取 3×3、5×5 或更大核，采样步长用 _MainTex_TexelSize 控制。

// 水平 Pass（垂直同理，交换 x/y）
float2 texel = _MainTex_TexelSize.xy * _BlurSize;
fixed4 color = tex2D(_MainTex, i.uv) * 0.227027;
color += tex2D(_MainTex, i.uv + float2(texel.x, 0)) * 0.316216;
color += tex2D(_MainTex, i.uv - float2(texel.x, 0)) * 0.316216;
color += tex2D(_MainTex, i.uv + float2(texel.x * 2, 0)) * 0.070270;
color += tex2D(_MainTex, i.uv - float2(texel.x * 2, 0)) * 0.070270;
return color;

Bloom 与运动模糊

  • Bloom：先提取高亮区域，再模糊，最后和原图叠加。高亮阈值、模糊半径、强度是三个主要参数。
  • 运动模糊：把当前帧和上一帧按速度/权重混合；需要保存上一帧的 RenderTexture，或使用速度缓冲。
// 简单的帧混合式运动模糊
fixed4 current = tex2D(_MainTex, i.uv);
fixed4 previous = tex2D(_PreviousFrame, i.uv);
return lerp(current, previous, _BlurAmount);

后处理的性能

  • 全屏 Pass 的填充率很高，移动端要控制分辨率/Pass 数。
  • 模糊、Bloom 通常用降采样 + 多 Pass；不要在原分辨率上做大核模糊。
  • Graphics.Blit 会产生额外的 RenderTexture 切换和带宽开销。
  • 用 Frame Debugger/GPU Profiler 确认是带宽、采样还是 ALU 瓶颈。

现代 Unity 备注：URP/HDRP 不调用 OnRenderImage；后处理要用 Renderer Feature、Volume、Full Screen Pass Renderer Feature 或自定义 RenderPass。抓屏/采样接口是 RTHandle/Blitter 等，和内置管线不同。

本章要点：后处理 = 场景渲染到 RT + 全屏 Pass；亮度/饱和度/对比度是颜色变换；边缘检测用卷积；高斯模糊拆两 Pass；Bloom 是高亮+模糊+叠加；移动端先算填充率和带宽。
