深度与法线纹理：让后处理知道“前后”和“朝向”

原书第 13 章把后处理从“二维颜色”推进到“三维信息”：深度纹理告诉你每个像素离相机多远，法线纹理告诉你表面朝向。有了它们，才能做运动模糊、全局雾、边缘检测、景深、SSAO 等效果。

深度纹理

内置管线可以通过 _CameraDepthTexture 获取深度。它通常是非线性的（受投影矩阵影响），需要转换：

sampler2D _CameraDepthTexture;

float depth = SAMPLE_DEPTH_TEXTURE(_CameraDepthTexture, i.uv);
float linearEyeDepth = LinearEyeDepth(depth);   // 观察空间深度
float linear01Depth = Linear01Depth(depth);     // 0~1 深度

LinearEyeDepth 返回的是“离相机的实际距离”，Linear01Depth 返回的是按近/远裁剪面归一化的值。做雾、景深、边缘检测时，先想清楚你需要哪一种。

重建世界坐标

只有深度还不够，要重建世界坐标，通常需要相机参数和视锥角。常见做法：

// 用原始深度和逆投影重建观察空间，再转到世界空间
float rawDepth = SAMPLE_DEPTH_TEXTURE(_CameraDepthTexture, i.uv);
float2 ndc = i.uv * 2 - 1;
float4 clipPos = float4(ndc, rawDepth, 1);
float4 viewPos = mul(unity_CameraInvProjection, clipPos);
viewPos /= viewPos.w;
float3 worldPos = mul(unity_CameraToWorld, float4(viewPos.xyz, 1)).xyz;

不同平台/投影矩阵的符号不同，实际实现还要处理 _ProjectionParams.x 的翻转；最稳的做法是使用当前管线提供的重建函数（URP 的 ComputeWorldSpacePosition 等）。

法线纹理

_CameraNormalsTexture 保存相机视角的法线（通常是观察空间）。它可以用来做边缘检测、SSAO、描边：

sampler2D _CameraNormalsTexture;

float3 viewNormal = tex2D(_CameraNormalsTexture, i.uv).rgb * 2 - 1;
float3 worldNormal = mul((float3x3)unity_CameraToWorld, viewNormal);

深度 + 法线可以做“Roberts 边缘检测”：深度差大或法线差大，就认为是边缘。比纯颜色边缘更稳定，不会把纹理细节误判成轮廓。

运动模糊

基于深度的运动模糊可以用“当前像素的世界坐标 → 上一帧屏幕坐标”的差来计算速度。没有速度缓冲时，也可以用相机运动/深度近似。原书给了一个简化版本，重点是理解“深度把像素从 2D 变回 3D”。

全局雾

用深度计算雾浓度：离相机越远，雾越浓。常见公式：

float fogDensity = saturate((linearEyeDepth - _FogStart) / (_FogEnd - _FogStart));
float3 finalColor = lerp(sceneColor, _FogColor.rgb, fogDensity * _FogIntensity);

基于高度的雾还会用世界坐标 Y 值，做出“低处更浓”的效果。

边缘检测的两种思路

方式输入特点
颜色边缘颜色/亮度简单，但会把纹理细节当成边缘。
深度/法线边缘深度、法线更接近几何轮廓，适合描边/卡通。

现代 Unity 备注：URP 需要显式开启 Depth Texture；_CameraNormalsTexture 需要 Depth Normals Pass。URP 的深度/法线获取、重建函数和内置管线不同，通常用 SampleSceneDepth、SampleSceneNormals、ComputeWorldSpacePosition 等。

本章要点：深度纹理要线性化；LinearEyeDepth 是距离，Linear01Depth 是归一化值；法线纹理通常在观察空间；深度+法线做边缘比颜色更稳；重建世界坐标要小心平台符号。
