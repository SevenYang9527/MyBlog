基于物理的渲染：从“像”到“可信”

原书第 18 章讲 PBR（Physically Based Rendering）。它先讲光、BRDF、漫反射/高光反射、菲涅耳，再讲 Unity 的 Standard Shader、反射探针、线性空间、HDR。PBR 的目标不是“照片级”，而是让材质在不同光照下有一致、可预测的表现。

BRDF

BRDF（Bidirectional Reflectance Distribution Function）描述“从某个入射方向来的光，有多少反射到某个观察方向”。它满足能量守恒：反射出去的能量不能超过入射能量。实时 PBR 通常把 BRDF 拆成漫反射项和高光项。

// 简化的反射方程（概念）
Lo = ∫ Li * f(l, v) * (N·L) dω

漫反射与高光

漫反射常用 Lambert：

diffuse = albedo / PI * NdotL;

高光常用微表面模型（Cook-Torrance）：

specular = D * G * F / (4 * NdotL * NdotV);
  • D：法线分布函数（常用 GGX/Trowbridge-Reitz）。
  • G：几何遮蔽函数（Smith 等）。
  • F：菲涅耳项（Schlick 近似）。

菲涅耳项描述“视角越掠射，反射越强”：

F = F0 + (1 - F0) * pow(1 - NdotV, 5);

F0 是垂直入射时的反射率。金属的 F0 来自 albedo，非金属通常约 0.04。

Metallic / Smoothness 工作流

贴图/参数含义
Albedo基础颜色；金属的 albedo 同时作为反射颜色。
Metallic0 = 非金属，1 = 金属；控制漫反射/高光的分配。

Unity Standard Shader

内置管线的 Standard Shader 实现了这套工作流，支持金属/非金属、法线、高度、遮挡、自发光、细节贴图等。它依赖反射探针、光照贴图、Light Probe 来提供环境反射/间接光；在线性空间 + HDR 下效果更稳定。

线性空间、Gamma 与 HDR

  • Gamma 空间：颜色在 sRGB 空间直接计算，简单但不物理。
  • 线性空间：光照在线性空间计算，最后再转 sRGB；更符合物理，颜色过渡更自然。
  • HDR：颜色值可以超过 1，保留高光/光源强度，配合 Bloom/Tone Mapping 使用。

如果颜色发灰、发暗、反射不对，先检查项目的 Color Space、纹理 sRGB、光照贴图/探针设置，再怀疑 Shader。

PBR 适合什么游戏

PBR 适合写实、次世代、需要一致材质表现的项目；风格化项目也可以用 PBR 作为基础，再叠加卡通/手绘效果。它不是“开了就好看”，材质作者需要理解金属度、粗糙度、反射探针和光照环境。

现代 Unity 备注：URP 的 Lit Shader、HDRP 的 Lit/StackLit 都是 PBR 工作流；Shader Graph 有 Metallic/Roughness 节点。反射探针、Light Probe、光照贴图仍然重要；不同管线的 BRDF/环境光实现不同，不要直接套内置 Standard 的参数。

本章要点：PBR = 能量守恒 + BRDF + 菲涅耳 + 金属度/粗糙度；漫反射用 Lambert，高光用微表面模型；Standard Shader 是内置管线的实现；线性空间/HDR/反射探针决定最终可信度；PBR 需要材质和光照环境配合。
