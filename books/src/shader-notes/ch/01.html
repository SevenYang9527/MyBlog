一本 2016 年的 Shader 书，今天怎么读

《Unity Shader 入门精要》由冯乐乐撰写，人民邮电出版社出版，全书 389 页，写作背景是 Unity 5 时代。它把 Shader 学习拆成五篇：基础篇讲渲染流水线和数学，初级篇讲光照、纹理和透明，中级篇讲复杂光照、高级纹理和动画，高级篇讲后处理、深度法线、非真实感渲染、噪声和优化，扩展篇讲表面着色器、PBR 和 Unity 5 的变化。

这本书的价值在于“把原理讲透再写代码”，而不是堆效果。它的代码主要面向内置渲染管线（Built-in Render Pipeline），今天仍然适合用来理解渲染管线、光照模型、纹理采样、透明排序和后处理的基本原理；但如果你在新项目里使用 URP/HDRP，很多 API、宏和 Shader 写法已经不同。

说明：本站收录的是原创“精要导读”，不是原书全文，也不复制原书插图。章节结构参考原书目录，技术解释、代码示例和“现代 Unity 备注”由本站重写；需要完整推导和原书示例时，请阅读原书。

五篇结构

篇章节解决的问题
基础篇第 1-4 章Shader 是什么、GPU 怎么画一帧、Unity Shader 怎么写、需要哪些数学。
初级篇第 5-8 章最小顶点/片元着色器、基础光照、纹理、透明。
中级篇第 9-11 章多光源/阴影、立方体纹理/渲染纹理、顶点与纹理动画。
高级篇第 12-16 章屏幕后处理、深度/法线纹理、卡通/素描、噪声、渲染优化。
扩展篇第 17-20 章表面着色器、PBR、Unity 5 的变化、继续学习的方向。

阅读建议

如果你刚开始学 Shader，建议按“第 2 章 → 第 3 章 → 第 4 章 → 第 5 章 → 第 6 章”的顺序读：先知道一帧怎么从顶点变成像素，再知道 Unity Shader 的文件结构，再补坐标变换和矩阵，最后写第一个可运行的光照 Shader。第 7 章之后的纹理、透明、后处理，可以按项目需要跳读。

读代码时不要只抄参数。每个 Shader 至少问三个问题：它在哪个渲染队列？它写了哪些渲染状态（Cull/ZWrite/ZTest/Blend）？它的光照和阴影依赖哪些宏？这三个问题答不出来，换一个模型或换一个管线就很容易“看起来一样、结果不对”。

今天的版本差异

原书写法今天更常见的写法说明
UNITY_MATRIX_MVPUnityObjectToClipPos(v.vertex)前者在较新版本中已不推荐直接使用；后者会处理平台差异。
fixed 类型half / floatfixed 仍可能被接受，但在现代 GPU 上通常等价于 half/float，建议明确精度。
表面着色器（Surface Shader）顶点/片元着色器、Shader Graph、HLSL表面着色器只属于内置管线；URP/HDRP 不使用它。
GrabPassURP 的 _CameraOpaqueTexture / SceneColorSRP 不支持 GrabPass，抓屏方式不同。
OnRenderImage 后处理URP Renderer Feature / VolumeSRP 不调用 OnRenderImage，后处理要用 Renderer Feature 或全屏 Pass。
内置光照/阴影宏URP 的 Lighting.hlsl / Shadows.hlsl宏名和包含文件都不同，不能直接混用。

本书的代码默认写内置管线，因为这是原书的语境；每章末尾会用“现代 Unity 备注”指出 URP/HDRP 的替代方案。站内还有一本《URP 进阶指南》，需要迁移时可以对照阅读。

本书的读法

每一章按“这一章讲什么 → 关键概念 → 一段最小代码/公式 → 现代 Unity 备注 → 本章要点”组织。代码只保留能说明问题的部分，省略模型、贴图、场景设置；你可以在自己的工程里补全。公式会尽量写成 Shader 里能直接用的形式，但不会替代原书的推导。

本章要点：原书是 Unity 5 时代的内置管线教材；原理仍然有效，API 需要更新。先读渲染流水线和数学，再写最小 Shader；每段代码都要能回答“队列、状态、光照/阴影依赖”三个问题。
