使用噪声：消融、水波与雾

原书第 15 章讲噪声。噪声看起来只是“随机纹理”，实际是把规则图案打散，让消融边缘不规则、水面有细节、雾有流动感。核心不是“生成一张随机图”，而是“用可重复的数学函数控制随机性”。

噪声的基本类型

类型特点常见用途
Value Noise对格点随机值插值，便宜，块状感明显。消融、雾、简单扰动。
Perlin Noise梯度噪声，连续、自然，计算量稍大。水面、云、地形。
FBM（分形噪声）多层噪声叠加，细节丰富。云、火焰、地形。
Worley Noise基于距离场，细胞状。水泡、皮肤、石块。

消融效果

用噪声值和一个阈值比较，低于阈值的片元丢弃；在阈值附近加一圈边缘色：

sampler2D _NoiseTex;
float _Threshold;
float _EdgeWidth;
fixed4 _EdgeColor;

fixed4 frag (v2f i) : SV_Target
{
    float noise = tex2D(_NoiseTex, i.uv).r;
    clip(noise - _Threshold);

    float edge = smoothstep(_Threshold, _Threshold + _EdgeWidth, noise);
    fixed4 baseColor = tex2D(_MainTex, i.uv);
    return lerp(_EdgeColor, baseColor, edge);
}

噪声纹理的 Wrap Mode 通常设为 Repeat，Tiling 控制消融块的大小。阈值随时间变化，就能做“逐渐消失”的动画。

水波效果

水面通常叠加两层法线/噪声，按不同速度滚动，再用菲涅耳控制反射/折射：

float2 uv1 = i.uv + _Time.y * _Speed1;
float2 uv2 = i.uv * 1.3 + _Time.y * _Speed2;
float3 n1 = UnpackNormal(tex2D(_NormalTex1, uv1));
float3 n2 = UnpackNormal(tex2D(_NormalTex2, uv2));
float3 normal = normalize(n1 + n2);

float fresnel = pow(1.0 - saturate(dot(normal, viewDir)), _FresnelPower);
float3 color = lerp(refraction, reflection, fresnel);

全局雾

噪声可以让雾“流动”起来，而不是一层均匀的颜色。常见做法是用世界坐标/时间采样噪声，叠加到雾密度上：

float noise = tex2D(_NoiseTex, worldPos.xz * _NoiseScale + _Time.y * _Speed).r;
float fog = saturate((depth - _FogStart) / (_FogEnd - _FogStart));
fog *= lerp(1.0, noise, _NoiseStrength);
float3 color = lerp(sceneColor, _FogColor.rgb, fog);

噪声的性能

  • 片元里多层 FBM 很贵；能用纹理预烘焙就用纹理。
  • 噪声采样次数、纹理分辨率、Tiling 都会影响带宽和 ALU。
  • 移动端优先用低分辨率噪声纹理 + 少量采样，避免在片元里跑多层循环。

现代 Unity 备注：Shader Graph 有 Noise 节点；URP 里同样可以用噪声纹理/程序噪声。VFX Graph 更适合粒子级噪声，不要把所有噪声都塞进表面 Shader。

本章要点：噪声是可重复的随机函数；消融用阈值 + 边缘色；水面用多层法线/噪声滚动 + 菲涅耳；雾用深度 + 噪声；片元里多层噪声很贵，优先预烘焙。
