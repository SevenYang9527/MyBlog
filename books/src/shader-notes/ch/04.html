Unity Shader 的文件结构与 ShaderLab

原书第 3 章讲的是“Unity 里的 Shader 长什么样”。它先区分材质（Material）和 Shader：材质是参数集合，Shader 是渲染程序；然后介绍 ShaderLab——Unity 用来描述 Shader 的外层语言，以及 Properties、SubShader、Pass、Fallback 这些结构。

材质和 Shader 的关系

Shader 定义“怎么算”，材质保存“用什么参数算”。同一个 Shader 可以有很多材质：红色塑料、蓝色金属、带纹理的木头，都是同一段 Shader 配不同的颜色、纹理、光滑度。运行时改材质参数，不需要重新编译 Shader。

// 材质上的参数会传给 Shader 的 Properties
material.SetColor("_Color", Color.red);
material.SetFloat("_Glossiness", 0.8f);
material.SetTexture("_MainTex", texture);

一个最小的 ShaderLab 结构

Shader "Custom/SimpleColor"
{
    Properties
    {
        _Color ("Color", Color) = (1, 1, 1, 1)
    }

    SubShader
    {
        Tags { "RenderType" = "Opaque" "Queue" = "Geometry" }

        Pass
        {
            CGPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "UnityCG.cginc"

            fixed4 _Color;

            struct appdata
            {
                float4 vertex : POSITION;
            };

            struct v2f
            {
                float4 pos : SV_POSITION;
            };

            v2f vert (appdata v)
            {
                v2f o;
                o.pos = UnityObjectToClipPos(v.vertex);
                return o;
            }

            fixed4 frag (v2f i) : SV_Target
            {
                return _Color;
            }
            ENDCG
        }
    }

    Fallback "Diffuse"
}

Properties：材质面板的接口

类型示例说明
Color_Color ("Color", Color) = (1,1,1,1)颜色，包含 alpha。
Vector_Offset ("Offset", Vector) = (0,0,0,0)四分量向量。
Float / Range_Gloss ("Gloss", Range(0,1)) = 0.5标量；Range 会在 Inspector 里显示滑条。
2D_MainTex ("Texture", 2D) = "white" {}2D 纹理；默认值可以是 "white"/"black"/"gray"。
Cube_Cube ("Cubemap", Cube) = "" {}立方体纹理。

纹理属性会自动带一个 _MainTex_ST 变量，ST 是 Scale 和 Translation 的缩写。用 TRANSFORM_TEX(uv, _MainTex) 可以把 Tiling/Offset 应用到 UV 上。

SubShader、Pass 与 Tags

一个 Shader 可以有多个 SubShader，Unity 会按顺序选择当前平台能用的第一个。每个 SubShader 可以包含多个 Pass；每个 Pass 是一次绘制，拥有自己的渲染状态和 Shader 代码。

标签/状态常见值作用
QueueBackground / Geometry / AlphaTest / Transparent / Overlay决定渲染顺序；透明物体通常用 Transparent。
RenderTypeOpaque / Transparent / TransparentCutout用于替换/后处理识别，也影响某些管线行为。
LightModeForwardBase / ForwardAdd / ShadowCaster内置管线中标记 Pass 的用途。
CullBack / Front / Off剔除背面/正面/不剔除；双面渲染用 Off。
ZWriteOn / Off是否写入深度；透明通常 Off。
ZTestLEqual / Always 等深度比较方式。
BlendSrcAlpha OneMinusSrcAlpha 等混合方式；透明/叠加效果用。

Unity Shader 的三种形式

  • 表面着色器（Surface Shader）：用 #pragma surface 写，Unity 帮你生成光照/阴影 Pass；代码短，但控制力有限，只属于内置管线。
  • 顶点/片元着色器（Vertex/Fragment Shader）：手写 vert 和 frag，控制最直接，是学习重点。
  • 固定函数着色器：早期写法，现代项目基本不用；原书也建议选择前两种。
// 表面着色器的最小形态（仅内置管线）
Shader "Custom/SurfaceDemo"
{
    Properties { _Color ("Color", Color) = (1,1,1,1) }
    SubShader
    {
        Tags { "RenderType" = "Opaque" }
        CGPROGRAM
        #pragma surface surf Lambert
        fixed4 _Color;
        struct Input { float2 uv_MainTex; };
        void surf (Input IN, inout SurfaceOutput o)
        {
            o.Albedo = _Color.rgb;
            o.Alpha = _Color.a;
        }
        ENDCG
    }
    Fallback "Diffuse"
}

Unity Shader 不等于“真正的 Shader”

Unity Shader 文件是一个“包装”：外层是 ShaderLab，里面可以写 CG/HLSL 代码，最终由 Unity 编译成目标平台的着色器。它和 HLSL/GLSL 的关系，类似“工程配置 + 源码”与“最终二进制”的关系。你可以在 Unity 里写 GLSL，但需要特定的写法，而且跨平台限制更多。

现代 Unity 备注：表面着色器和固定函数着色器都属于内置管线的历史；URP/HDRP 使用 HLSL + Shader Graph。ShaderLab 的 Properties/SubShader/Pass 结构在 SRP 中仍然存在，但 LightMode、光照宏、后处理方式都变了。

本章要点：材质存参数，Shader 存逻辑；ShaderLab 负责结构，CG/HLSL 负责计算；Properties 是材质面板接口；SubShader/Pass 决定平台和绘制；Queue/Cull/ZWrite/ZTest/Blend 是渲染状态的核心。
