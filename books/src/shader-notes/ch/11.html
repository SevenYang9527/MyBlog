高级纹理：立方体纹理、渲染纹理与程序纹理

原书第 10 章把纹理从 2D 扩展到“环境”和“屏幕”：立方体纹理做反射/折射，渲染纹理做镜子/玻璃，程序纹理用代码生成图案。它们共同说明：纹理不只是颜色贴图，也可以是方向查找表、屏幕快照或数学函数。

立方体纹理（Cubemap）

立方体纹理由六个面组成，用方向向量采样。常见用途：天空盒、环境反射、折射、菲涅耳效果。

samplerCUBE _CubeMap;

float3 worldNormal = UnityObjectToWorldNormal(v.normal);
float3 worldViewDir = normalize(_WorldSpaceCameraPos - worldPos);
float3 reflectDir = reflect(-worldViewDir, worldNormal);
float3 reflection = texCUBE(_CubeMap, reflectDir).rgb;

反射越强，物体越像金属/镜面；折射则用 refract，并通常按折射率混合。菲涅耳（Fresnel）用视角和法线的点积控制“边缘更亮”的反射：

float fresnel = pow(1.0 - saturate(dot(worldNormal, worldViewDir)), _FresnelPower);
float3 color = lerp(refraction, reflection, fresnel);

渲染纹理与 GrabPass

内置管线里，GrabPass 可以把当前屏幕抓成一张纹理，用来做镜子、玻璃、热扰动：

GrabPass { "_GrabTexture" }

sampler2D _GrabTexture;

fixed4 frag (v2f i) : SV_Target
{
    float2 uv = i.screenPos.xy / i.screenPos.w;
    fixed4 screenColor = tex2D(_GrabTexture, uv);
    return screenColor * _Tint;
}

也可以手动用 RenderTexture + 额外相机渲染场景，再把结果贴到物体上。镜子通常就是“从镜面视角再渲染一次场景”。

程序纹理

程序纹理不依赖美术贴图，用数学函数在 Shader 里生成图案：条纹、格子、噪声、渐变。优点是可控、可无限分辨率；缺点是不能直接用美术绘制，复杂图案的代码成本高。

float checker(float2 uv, float scale)
{
    float2 c = floor(uv * scale);
    return fmod(c.x + c.y, 2.0);
}

fixed4 frag (v2f i) : SV_Target
{
    float c = checker(i.uv, 8.0);
    return lerp(_ColorA, _ColorB, c);
}

反射探针与天空盒

Unity 的 Reflection Probe 会把周围环境渲染成立方体纹理，供材质采样。天空盒本身也是一个 Cubemap。用反射探针时要注意：探针的位置、混合范围、HDR/线性空间设置都会影响反射结果。

现代 Unity 备注：URP/HDRP 不支持内置管线的 GrabPass；抓屏要用 _CameraOpaqueTexture、_CameraColorTexture 或 Renderer Feature。反射探针仍然存在，但 Shader 采样方式、包含文件和光照宏不同。屏幕空间反射（SSR）是另一条路线。

本章要点：Cubemap 用方向采样，适合环境反射/折射/天空盒；GrabPass/RenderTexture 适合镜面和屏幕效果；程序纹理用数学换灵活；反射探针负责环境反射；SRP 下抓屏方式完全不同。
