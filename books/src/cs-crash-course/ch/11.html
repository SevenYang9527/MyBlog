机器学习、计算机视觉与 NLP：让机器从数据里找规律

第三十四到三十六集讲 AI 的三条主线：机器学习让程序从数据中学习，计算机视觉让机器“看懂”图像，自然语言处理让机器“理解/生成”语言。它们共享一个思路：不再手写所有规则，而是用数据 + 模型 + 优化来找规律。

机器学习的基本范式

类型数据典型任务
监督学习输入 + 标签分类、回归、检测
无监督学习只有输入聚类、降维、异常检测
强化学习环境 + 奖励游戏、机器人控制、决策

训练流程通常包括：收集/清洗数据、特征工程、划分训练/验证/测试集、选择模型、定义损失函数、用梯度下降优化参数、评估泛化能力。过拟合是常见问题：模型在训练集上很好，在新数据上很差；正则化、更多数据、交叉验证和早停可以缓解。

计算机视觉

图像在计算机里是像素矩阵。传统视觉靠手工特征（边缘、角点、SIFT 等）；深度学习用卷积神经网络（CNN）自动学习特征：卷积核在图像上滑动，提取局部模式；池化降低分辨率；多层堆叠从边缘 → 纹理 → 物体部件 → 物体。今天的目标检测、分割、人脸识别、自动驾驶都依赖这类模型。

自然语言处理

NLP 让机器处理文本/语音：分词、词性、句法、语义、情感、翻译、问答、对话。早期用规则/统计（n-gram），后来用词向量（word embeddings）和 RNN/LSTM；2017 年之后的 Transformer/注意力机制，成为大语言模型的基础。

2026 补充：Transformer/注意力机制和大规模预训练把 NLP 推向大语言模型（LLM）；多模态模型把文本、图像、音频放在同一空间；扩散模型改变图像生成；RAG、工具调用和 Agent 让模型接入外部知识/行动。与此同时，幻觉、版权、偏见、能耗和安全对齐成为必须面对的问题。

本章要点：机器学习用数据/模型/损失/优化找规律；监督/无监督/强化学习对应不同数据形态；CNN 用卷积/池化提取视觉特征；NLP 从规则/统计走向词向量、RNN、Transformer；大模型能力强，但需要评估、对齐和成本控制。
