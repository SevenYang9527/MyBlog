用开关思考：布尔逻辑、二进制与 ALU

第三到五集把“计算机为什么能用电路算数”讲清楚了：先有布尔逻辑，把真假命题变成 0/1；再用逻辑门实现与或非；最后用二进制表示数字，用加法器和 ALU 做算术。理解这三步，你就理解了 CPU 最底层的“算”是怎么发生的。

布尔逻辑：把推理变成运算

乔治·布尔把“真/假”抽象成两个值，并定义了与、或、非等运算。今天计算机里的 1 和 0 不是“数字”，而是“电平/真假”的表示。最基本的逻辑门：

门规则直觉
NOT输入取反“不是”
AND全 1 才输出 1“并且”
OR有 1 就输出 1“或者”
XOR不同才输出 1“要么…要么…”
NANDAND 再取反万能门，可以组合出其他门

逻辑门可以用继电器、真空管或晶体管实现。晶体管像电控开关：栅极电压控制源漏之间是否导通。把开关串/并联，就能得到 AND/OR；再组合，就能得到任意逻辑函数。

二进制：用位置表示大小

十进制有 0-9 十个数码，二进制只有 0/1。一个二进制数的每一位对应 2 的幂：

1011₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 8 + 0 + 2 + 1 = 11₁₀

8 位组成一个字节，可以表示 0-255；十六进制用 0-9/A-F 表示 4 位二进制，写地址和颜色更方便。字符用编码表表示：ASCII 覆盖英文和常见符号，Unicode 覆盖全球文字和 emoji。

负数与小数

  • 符号-数值：最高位当符号位，简单但有 +0/-0 两个零，加减法麻烦。
  • 补码：负数用“取反加一”表示，让减法可以复用加法器；现代整数普遍用补码。
  • 浮点数：用符号位、指数、尾数表示小数，遵循 IEEE 754；能表示很大/很小的范围，但有精度误差（0.1 + 0.2 不等于 0.3 就是典型例子）。

ALU：算术逻辑单元

ALU 负责加减、与或非、比较、移位等操作。最基础的加法器是半加器：两个输入位相加，输出“和”和“进位”；两个半加器加一个 OR 门组成全加器，可以接收低位进位。把多个全加器串起来，就是行波进位加法器。

2026 补充：今天的 CPU 普遍是 64 位，但“位宽”不是唯一指标：SIMD 向量指令、GPU 的并行 ALU、AI 加速器的矩阵乘加单元，都是把“算术”做得更宽、更专用。浮点精度也从 FP32/FP64 扩展到 FP16/BF16/FP8，用于推理和训练。

本章要点：布尔逻辑把真假变成 0/1；逻辑门由晶体管开关组合而成；二进制用位置表示大小；补码让减法复用加法器；ALU 用控制信号选择运算，是 CPU 的算术核心。
