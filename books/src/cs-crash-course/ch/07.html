第 7 集 中央处理器

CPU 的核心循环是取指—译码—执行：根据程序计数器 PC 从内存读取指令，译码器解析操作码/操作数，ALU/访存/跳转执行，最后写回并更新 PC。

时钟驱动流水线；程序计数器、指令寄存器、控制单元、寄存器堆、ALU 共同协作。指令集是 CPU 的“词汇表”，汇编是机器码的可读形式。

这一集把前面所有部件串起来：CPU 不是单一芯片，而是“控制 + 运算 + 存储 + 通信”的组合。

2026 补充：现代 CPU 把取指/译码/执行拆成多级流水线，支持超标量、乱序、分支预测、推测执行、缓存和多核；性能提升更多来自并行与专用化。

本集要点：CPU 循环：取指 → 译码 → 执行 → 写回 → 更新 PC；时钟/PC/IR/控制单元/ALU/寄存器共同工作；指令集是 CPU 的词汇表。
