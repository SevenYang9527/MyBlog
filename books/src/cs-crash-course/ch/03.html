寄存器、内存与 CPU：让机器“记住”并“执行”

第六到九集把计算机从“能做一次加法”推进到“能执行程序”：先用触发器/寄存器保存 1 位，再用内存保存大量数据，最后用 CPU 的取指—译码—执行循环把指令变成动作。现代 CPU 的流水线、乱序执行、缓存和多核，都是在这个循环上做加速。

从 1 位记忆到内存

触发器/锁存器可以用逻辑门保存 1 位：把输出反馈到输入，电路就能“锁住”当前值。多个触发器并排，就是一个寄存器；大量存储单元加上地址译码器，就是 RAM。CPU 通过地址总线选中某个单元，通过数据总线读写。

层次特点速度/成本
寄存器CPU 内部，数量很少最快、最贵
SRAM/缓存速度快，集成在 CPU 附近快、较贵
DRAM主内存，容量大，需要刷新中等
SSD/HDD持久存储，容量更大慢、便宜

CPU 的取指—译码—执行

CPU 的核心循环可以简化为：

  1. 取指（Fetch）：根据程序计数器 PC 从内存读取下一条指令。
  2. 译码（Decode）：解析操作码和操作数，决定做什么、操作哪些寄存器/内存。
  3. 执行（Execute）：ALU 计算、访存、跳转，结果写回寄存器/内存。
  4. 更新 PC：顺序执行下一条，或跳转到新地址。

指令集是 CPU 的“词汇表”：有的 CPU 指令少而简单（RISC），有的指令多而复杂（CISC）。汇编语言是机器码的可读形式，汇编器把它翻译成 0/1；函数调用、栈、调用约定则让程序可以拆分和复用。

现代 CPU 的加速手段

  • 流水线：把取指/译码/执行拆成多级，让不同指令同时处于不同阶段。
  • 超标量/乱序：一个周期发射多条指令，按依赖关系重排执行。
  • 分支预测/推测执行：提前猜分支方向并执行，猜错再回滚。
  • 缓存：利用局部性，把常用数据放在离 CPU 更近的地方。
  • 多核/超线程：多个核心并行，提升吞吐。

2026 补充：今天的性能提升更多来自“专用化 + 并行”：Apple M 系列/ARM 的能效核与性能核、chiplet/先进封装、GPU/NPU 加速。分支预测和推测执行也带来了 Spectre/Meltdown 这类侧信道安全问题，性能优化和安全性需要一起考虑。

本章要点：触发器保存 1 位，寄存器/内存保存大量数据；CPU 按取指—译码—执行循环工作；指令集、汇编、栈和调用约定让程序可组合；流水线、乱序、缓存、多核是现代 CPU 的主要加速手段。
