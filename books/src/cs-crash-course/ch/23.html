第 23 集 屏幕与 2D 图形显示

CRT/LCD 把电信号变成像素。屏幕图像可以看成一张二维像素网格，每个像素有颜色；帧缓冲保存当前画面。图形系统要处理分辨率、色深、刷新率、光栅化（把几何图形变成像素）和合成（把多个图层叠加）。

光栅显示把图像存成像素网格；矢量显示用几何描述，渲染时再转成像素。现代 GUI 通常是“矢量/文字 + 位图 + 合成”的混合。

这一集把“电信号”变成“可见画面”：像素、帧缓冲、光栅化是 2D 图形的基础。

2026 补充：高刷新率/高分辨率/HDR/广色域成为主流；GPU 合成、硬件加速和显示管线（色彩管理）让“像素”背后的工程更复杂。

本集要点：屏幕是像素网格；帧缓冲保存画面；光栅化把几何变成像素；分辨率/色深/刷新率/合成是 2D 图形的基础。
