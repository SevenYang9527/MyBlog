第 30 集 万维网

万维网的核心是“超文本”：文档之间用链接互相引用。URL 定位资源，HTTP 传输请求/响应，HTML 描述结构，浏览器负责解析、渲染和交互。搜索引擎用爬虫、索引和排序算法，把“找网页”变成“搜关键词”。

Web 2.0 让用户生成内容/社交/API 成为主流；Cookie/Session 在无状态 HTTP 上维持登录状态；前端/后端/数据库/CDN 构成现代 Web 应用。

这一集把“互联网”变成“信息空间”：URL/HTTP/HTML/浏览器是四个关键词。

2026 补充：HTTP/2/3、WebAssembly、PWA、边缘渲染、API/微服务和 AI 生成内容继续改变 Web；隐私/广告/内容审核/可访问性是长期议题。

本集要点：万维网 = 超文本 + URL + HTTP + 浏览器；搜索引擎用爬虫/索引/排序；Cookie/Session 维持状态；Web 2.0 让用户生成内容和 API 成为主流。
