3D 图形与网络：把世界画出来，也把世界连起来

第二十七到二十九集从“画面”和“连接”两个方向扩展计算机的能力：3D 图形把三维场景投影到二维屏幕，网络把多台计算机连成互联网。它们看起来无关，但都需要“分层”和“流水线”的工程思维。

3D 图形管线

3D 场景通常由顶点、三角形/多边形和材质组成。渲染管线大致是：

  1. 模型/顶点：顶点从模型空间变换到世界/观察/裁剪空间。
  2. 光栅化：把三角形覆盖的像素找出来，插值属性。
  3. 片元着色：采样纹理、计算光照、阴影、反射。
  4. 深度/混合：决定像素是否可见、如何与背景混合。
  5. 输出：写入帧缓冲，显示到屏幕。

Z-buffer 用每个像素的深度解决遮挡；纹理映射把 2D 图片贴到 3D 表面；光照模型决定明暗。GPU 把大量顶点/像素并行处理，是现代游戏和实时渲染的核心。

计算机网络

网络把“发送数据”拆成分层问题：物理介质、链路、网络、传输、应用。每一层只关心自己的职责，上层不需要知道下层怎么传。

层典型协议/概念解决的问题
链路层Ethernet、Wi-Fi、MAC同一局域网内怎么找到设备、怎么传帧
网络层IP、路由、BGP跨网络怎么寻址、怎么选路
传输层TCP、UDP端到端可靠性/顺序/拥塞控制
应用层HTTP、DNS、SMTP具体应用怎么交换数据

互联网是“网络的网络”：数据被切成包，经过路由器逐跳转发；TCP 负责可靠传输和重传，UDP 负责低延迟但不可靠；DNS 把域名解析成 IP；BGP 让不同运营商网络互相通告路由。

2026 补充：实时渲染走向光线追踪、路径追踪、DLSS/FSR 等超分与降噪；图形 API 转向 Vulkan/Metal/DX12 和 WebGPU。网络侧，5G/Wi-Fi 6/7、IPv6、CDN、边缘计算和云网络让“低延迟”成为新的竞争点；QUIC/HTTP3 在 UDP 上重建可靠传输。

本章要点：3D 图形是“顶点 → 变换 → 光栅化 → 片元 → 帧缓冲”的流水线；网络是“链路 → 网络 → 传输 → 应用”的分层；IP 负责寻址/路由，TCP/UDP 负责端到端传输；分层和并行是两者共同的工程方法。
