如果你要在多个 Quality 选项之间切换，请通过 Project Settings 在 Quality 面板中为渲染管线资源（Render Pipeline Asset）选择一个质量等级（Quality Level）。请注意，如果没有设置质量等级，渲染管线资源会默认使用 Graphics 面板中设置为 Scriptable Render Pipeline Asset 的那一个。这可能会在你尝试调整某个 URP Asset 的画质设置时造成一些困惑。

例如，你可能会误以为 URP Asset 中设置的质量等级，就是 Scene 视图和 Game 视图当前正在使用的那个等级。

修改 URP Asset

注意：如果你启用了 URP 2D Renderer，URP Asset 中与 3D 渲染相关的一些选项不会影响你最终的应用或游戏。2D Renderer Asset 可在 Edit > Project Settings > Graphics 的 Scriptable Render Pipeline Settings 下找到。

这张图展示了 Inspector 中的一个 URP Asset 及其所有可用设置。要了解每项设置的更多信息，请参阅 URP 文档。

URP Asset 的 Quality 面板允许你将 HDR 格式设置为 64 位，以获得更好的保真度。但要注意，这会带来性能损失并需要额外的内存，因此在低端硬件上应避免使用该设置。

Quality 面板的另一个功能是可以启用 LOD 淡入淡出（LOD Cross Fade）。LOD 是一种用于降低渲染远处网格所需 GPU 开销的技术。随着摄像机的移动，不同的 LOD 会被切换，以提供恰当的质量水平。LOD 淡入淡出可以让不同 LOD 几何体之间的过渡更平滑，避免切换时出现生硬的跳变与突现。

将示例项目从内置渲染管线转换为 URP

Unity 的演示项目 Viking Village URP 展示了 URP 的多种能力，包括光照探针（Light Probes）、反射探针、使用自定义 ScriptableRenderPass 的水面特效、通过 Shader Graph 转换的着色器，以及 URP 后处理。该项目可在 Unity Asset Store 上免费获取。

在编辑器中打开 Viking Village URP，跟着本节的步骤一起操作。首先点击 Add to My Assets，把这个演示项目添加到编辑器中可用的 Packages 列表里。

然后通过 Unity Hub 创建一个新的 3D 项目（不必使用 URP 模板）。进入 Window > Package Manager，从 Packages 下拉菜单中选择 My Assets > Viking Village URP，然后点击 Import。

此时会出现几条警告信息（见下图）。第一条警告提示你：导入一个完整项目会影响当前的 Project Settings，但由于你创建的是一个空项目，因此可以安全地继续。第二条警告提醒你要安装或升级某些包。点击默认的蓝色按钮即可。这一步是必需的，可以避免出现错误的光照设置，因为 URP 默认使用线性色彩空间（linear color space），而内置渲染管线的默认值是伽马色彩空间（gamma color space）。

下载完成后，会打开下图所示的面板。请确保所有内容都保持勾选，然后点击 Import。

等待所有资源导入完成，然后打开 Viking Village > Scenes > The_Viking_Village 中的演示场景。点击 Window > Package Manager，在下拉菜单中选择 Unity Registry，然后选择 Universal RP。将 URP 包更新到 14.x。

在 Graphics 面板中通过 Scriptable Render Pipeline Asset 设置的 URP Asset 名为 Viking Village > Rendering > VikingVillageUniversal。它是为高端硬件配置的，因此在较旧的硬件上可能只能以较低的帧率运行。

按照以下步骤测试不同的质量等级：

  1. 通过 Window > Rendering > Render Pipeline Converter 生成一组资源。
  2. 选择 Built-in Render Pipeline to URP 选项，然后选择 Rendering Settings。
  3. 点击 Initialize Converters。
  4. 面板中会出现若干 Settings 选项；点击 Convert Assets 以创建 URP Asset。
  5. 这些 URP Asset 会通过 Project Settings > Quality 面板分配给各个可用的质量等级。
  6. 最高质量的资源会替换 Graphics 面板中的 VikingVillageUniversal。Viking Village > Rendering > VikingVillageUniversal_Renderer 使用了渲染器功能（Renderer Features）和水面特效。
  7. 要恢复这些设置，请把上面的渲染器添加到 Renderer List，并将它设为每个质量等级所用 URP Asset 的默认渲染器。现在你就可以在 Quality 面板中快速切换质量等级了。
