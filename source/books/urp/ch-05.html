贴花（Decals）

Decal Projector 是为网格添加细节的一种绝佳方式。你可以用它们制作子弹孔、脚印、标牌、裂缝等元素。由于它们采用投影框架，因此能够贴合不平整或弯曲的表面。要在 URP 中使用 Decal Projector，你需要找到项目的 Renderer Data 资源，并添加 Decal Renderer Feature。

添加 Decal Renderer Feature

在大多数情况下，你可以直接采用默认设置。

现在你的场景已经可以使用贴花了。要创建贴花，请在 Hierarchy 视图中右键单击，然后选择 Rendering > URP Decal Projector。默认情况下，该投影器使用 Decal 材质，它会将一个白色方块投影到表面上。使用常规工具来定位和调整投影器的朝向。在 Inspector 中调整 Width、Height 和 Projection Depth。

要自定义贴花，请使用 Shader Graph > Decal 着色器创建一个材质。该着色器有三个输入：Base Map、Normal Map 和 Normal Blend。材质准备就绪后，将其指定给 Decal Projector。

Decal Projector 设置

Decal Projector 的 Inspector 包含三个 Editing Mode 按钮：Scale、Crop 和 Pivot/UV，你将在后文中读到相关内容。

默认情况下，投影器会影响其视锥体内的任何表面。Decal Renderer Feature 包含 Use Rendering Layers 设置。启用该设置即可针对特定网格进行投影。

Decal Renderer Feature 设置

请回顾 Rendering Layers 一节，了解如何设置和使用这一渲染选项。以下是设置贴花的步骤：

  1. 使用 Edit > Project Settings… > Graphics > URP Global Settings 为一个 Rendering Layer 命名。
  2. 选择你希望接收投影器影响的网格。在 Inspector 中找到 Mesh Renderer > Additional Settings > Rendering Layer Mask，并将已命名的 Rendering Layer 添加到该遮罩中。
  3. 选择 URP Decal Projector，并在 Inspector 中为 Rendering Layers 属性选择已命名的 Rendering Layer。
