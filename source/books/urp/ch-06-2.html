着色器辅助函数（shader helper functions）是写着色器的基础。它们不仅能节省时间，而且本身就是常用计算的高度优化实现。这个 include 文件包含许多辅助函数，涉及以下方面：

  • 平台相关的函数（Platforms-specific functions）
  • 通用数学函数（Common math functions）
  • 纹理工具（Texture utilities）
  • 纹理格式采样（Texture format sampling）
  • 深度编码/解码（Depth encoding/decoding）
  • 空间变换（Space transformations）
  • 地形/笔刷高度图编码/解码及其他杂项工具

下表列出了其中一些。类型 real 是在文件中设定的；根据不同的标志，它可能是 half，也可能是 float。

辅助函数（Helper function）
real DegToRad(real deg)
real RadToDeg(real rad)
bool IsPower2(uint x)
real FastACosPos(real inX)
real FastASin(real x)
real FastATan(real x)
uint FastLog2(uint x)
real3 Orthonormalize(real3 tangent, real3 normal)
real Pow4(real x)
float4x4 Inverse(float4x4 m)
float ComputeTextureLOD(float2 uv, float bias = 0.0)
float Linear01Depth(float depth, float4 zBufferParam)

预处理器宏

预处理器宏（preprocessor macros）方便实用，而且经常被使用。在把内置渲染管线（Built-in Render Pipeline）的着色器移植到新的 URP 着色器时，你需要把内置渲染管线的宏替换为对应的 URP 宏。

下表给出了几个示例。

内置渲染管线（Built-in Render Pipeline） URP
UNITY_PROJ_COORD(a) 替换为 a.xy/a.w
UNITY_INITIALIZE_OUTPUT(type, name) ZERO_INITIALIZE(type, name)
阴影贴图（Shadow mapping）*
UNITY_DECLARE_SHADOWMAP(tex) TEXTURE2D_SHADOW_PARAM(textureName, samplerName)**
UNITY_SAMPLE_SHADOW(tex, uv) SAMPLE_TEXTURE2D_SHADOW(textureName, samplerName, coord3)
UNITY_SAMPLE_SHADOW_PROJ(tex, uv) SAMPLE_TEXTURE2D_SHADOW(textureName, samplerName, coord4.xyz/coord4.w)
纹理/采样器声明（Texture/sampler declaration）***
UNITY_DECLARE_TEX2D(name) TEXTURE2D(textureName);
SAMPLER(samplerName);
UNITY_DECLARE_TEX2D_NOSAMPLER(name) TEXTURE2D(textureName);
UNITY_SAMPLE_TEX2D_SAMPLER(name,samplername,uv) SAMPLE_TEXTURE2D(textureName, samplerName, coord2)

表格注释：

  • * 阴影贴图相关的宏需要这个 shadow include 文件。
  • ** _PARAM 是可用于声明带纹理与采样器参数的函数的一组宏。更多信息请参阅这份文档。
  • *** 关于内置渲染管线的纹理/采样器声明，请阅读这份文档。

LightMode 标签

LightMode 标签定义了一个 Pass 在光照管线中的角色。在内置渲染管线中，大多数需要与光照交互的着色器都写成表面着色器（Surface Shader），所有必要的细节都已处理妥当。然而，内置渲染管线中的自定义着色器需要使用 LightMode 标签来指明该 Pass 在光照管线中如何被看待。

下表给出了内置渲染管线所用的 LightMode 标签与 URP 所期望的标签之间的对应关系。若干旧的内置渲染管线标签在 URP 中不受支持：PrepassBase、PrepassFinal、Vertex、VertexLMRGBM 和 VertexLM。同时，URP 中还有一些标签在内置渲染管线中没有对应项。为 URP 编写着色器时，最好先看看官方提供的着色器以及它们使用的 Pass。下面的代码示例展示了 Lit Shader 中的部分代码。完整着色器见此处。

内置渲染管线（Built-in Render Pipeline，在此阅读更多） 说明 URP（在此阅读更多）
Always 始终渲染；不应用任何光照 —
ForwardBase 用于前向渲染（Forward rendering）；应用环境光、主平行光、顶点/球谐（SH）光照以及光照贴图 UniversalForward
ForwardAdd 用于前向渲染；应用逐像素的叠加光照，每盏光源一个 Pass UniversalForward
Deferred 用于延迟着色（Deferred Shading）；渲染 G-buffer UniversalGBuffer
ShadowCaster 把物体深度渲染进阴影贴图或深度纹理 ShadowCaster
MotionVectors 用于计算逐物体的运动矢量（motion vector） MotionVectors
— URP 在前向渲染路径（Forward Rendering Path）中使用此标签值；该 Pass 渲染物体几何并计算所有光照贡献。 UniversalForwardOnly
— URP 在 2D Renderer 中使用此标签值；该 Pass 渲染物体并计算 2D 光照贡献。 Universal2D
— 该 Pass 只从摄像机视角把深度信息渲染进深度纹理。 DepthOnly
— 该 Pass 仅在 Unity 编辑器中烘焙光照贴图时执行；构建 Player 时 Unity 会把该 Pass 从着色器中剥离。 Meta
— 使用此标签值可在渲染物体时额外绘制一个 Pass；它在前向与延迟渲染路径中均有效。

当某个 Pass 没有 LightMode 标签时，URP 会把此标签值用作默认值。		 SRPDefaultUnlit

UniversalForward 和 ShadowCaster 这两个 Pass 涉及许多 pragma 指令和两个 include 文件。检查 include 文件中的代码，将有助于你创建适合自己需求的自定义版本。

//  前向 Pass。在单个 Pass 中为所有光照着色。GI + 自发光 + 雾效
Pass
{
   // Lightmode 与 UniversalRenderPipeline.cs 中设置的 ShaderPassName 匹配。
   // SRPDefaultUnlit 以及没有 LightMode 标签的 Pass 也会由通用渲染管线渲染
   Name "ForwardLit"
   Tags{"LightMode" = "UniversalForward"}
   Blend[_SrcBlend][_DstBlend], [_SrcBlendAlpha][_DstBlendAlpha]
   ZWrite[_ZWrite]
   Cull[_Cull]
   AlphaToMask[_AlphaToMask]
   HLSLPROGRAM
   #pragma exclude_renderers gles gles3 glcore
   #pragma target 4.5
   …
   #pragma vertex LitPassVertex
   #pragma fragment LitPassFragment
   #include "Packages/com.unity.render-pipelines.universal/Shaders/Lit-Input.hlsl"
   #include "Packages/com.unity.render-pipelines.universal/Shaders/Lit-ForwardPass.hlsl"
   ENDHLSL
}

Pass
{
   Name "ShadowCaster"
   Tags{"LightMode" = "ShadowCaster"}
   ZWrite On
   ZTest LEqual
   ColorMask 0
   Cull[_Cull]
   HLSLPROGRAM
   #pragma exclude_renderers gles gles3 glcore
    …
   #pragma vertex ShadowPassVertex
   #pragma fragment ShadowPassFragment
   #include "Packages/com.unity.render-pipelines.universal/Shaders/Lit-Input.hlsl"
   #include "Packages/com.unity.render-pipelines.universal/Shaders/ShadowCasterPass.hlsl"
   ENDHLSL
}
