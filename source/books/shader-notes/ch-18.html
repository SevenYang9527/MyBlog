表面着色器：Unity 帮你写了什么

原书第 17 章专门拆表面着色器（Surface Shader）。表面着色器是内置管线的一种“高层写法”：你只写表面属性（albedo、normal、emission、alpha、smoothness、metallic），Unity 自动生成顶点/片元着色器、光照循环和阴影 Pass。代码短，但黑盒多。

一个表面着色器

Shader "Custom/SurfaceDemo"
{
    Properties
    {
        _Color ("Color", Color) = (1,1,1,1)
        _MainTex ("Albedo", 2D) = "white" {}
        _Glossiness ("Smoothness", Range(0,1)) = 0.5
        _Metallic ("Metallic", Range(0,1)) = 0.0
    }

    SubShader
    {
        Tags { "RenderType" = "Opaque" }
        LOD 200

        CGPROGRAM
        #pragma surface surf Standard fullforwardshadows
        #pragma target 3.0

        sampler2D _MainTex;
        fixed4 _Color;
        half _Glossiness;
        half _Metallic;

        struct Input
        {
            float2 uv_MainTex;
        };

        void surf (Input IN, inout SurfaceOutputStandard o)
        {
            fixed4 c = tex2D(_MainTex, IN.uv_MainTex) * _Color;
            o.Albedo = c.rgb;
            o.Metallic = _Metallic;
            o.Smoothness = _Glossiness;
            o.Alpha = c.a;
        }
        ENDCG
    }
    Fallback "Diffuse"
}

编译指令

指令作用
#pragma surface surf Standard指定表面函数和光照模型（Standard/Lambert/BlinnPhong 等）。
fullforwardshadows前向渲染中支持所有阴影类型。
alpha启用透明，生成 alpha 混合 Pass。
alpha:auto根据输出自动选择 alpha 测试/混合。
vertex:vert自定义顶点函数。
finalcolor:color自定义最终颜色函数。
addshadow为自定义顶点动画生成匹配的阴影 Pass。

两个结构体

  • Input：你声明需要的输入，例如 uv_MainTex、worldNormal、worldPos、viewDir；Unity 会帮你填充。
  • SurfaceOutput / SurfaceOutputStandard：你输出 Albedo、Normal、Emission、Alpha、Metallic、Smoothness、Occlusion 等；Unity 根据光照模型生成后续计算。

Unity 背后做了什么

表面着色器会被编译成多个 Pass：前向基础 Pass、前向附加 Pass、阴影 Pass，以及可能的延迟 Pass。Unity 会插入光照循环、阴影采样、雾、光照贴图等代码。你可以用“Show Generated Code”查看展开结果，理解为什么表面着色器方便但也难调。

优点与缺点

优点缺点
代码短，光照/阴影自动处理。黑盒多，出问题难定位。
适合快速做 Standard 风格材质。只支持内置管线，URP/HDRP 不可用。
自动生成多 Pass/变体。变体多、编译慢、包体大。
容易接入光照贴图/探针。对特殊效果/自定义光照控制力有限。

现代 Unity 备注：表面着色器是内置管线的历史；URP/HDRP 不使用 #pragma surface。新项目应使用 Shader Graph 或手写 HLSL；如果维护老项目，理解表面着色器生成的 Pass 仍然有助于排查阴影/光照问题。

本章要点：表面着色器 = 表面函数 + 光照模型 + 自动生成的 Pass；Input 接数据，SurfaceOutput 出属性；优点是短，缺点是黑盒/变体多/只限内置管线；新项目用 Shader Graph/HLSL。
