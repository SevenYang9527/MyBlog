还有更多内容：从这本书走向更大的渲染世界

原书第 20 章很短，讲“还有更多内容”：如果想深入渲染，可以看哪些书、论文、博客；世界很大，Shader 只是入口。本站把这一章扩展成一份“继续学习 + 常用宏/迁移表”的附录，方便读完前 19 章后继续查。

继续学习的方向

方向可以学什么和本书的关系
图形学基础线性代数、光栅化、光照、纹理、阴影、全局光照补足第 2、4、6、9 章背后的理论。
实时渲染PBR、IBL、阴影、后处理、抗锯齿、GPU 架构接第 12-19 章。
引擎/管线URP/HDRP、Render Graph、Shader Graph、Compute Shader把内置管线知识迁移到现代管线。
工具/调试RenderDoc、Frame Debugger、GPU Profiler、平台工具把“看起来不对”变成可定位的问题。
美术/风格色彩、构图、材质、光照设计Shader 最终服务于画面。

调试清单

  • 颜色不对：先看 Color Space、纹理 sRGB、光照贴图/探针、材质参数。
  • 光照不对：先看渲染路径、光源类型、法线空间、阴影宏。
  • 透明不对：先看 Queue、ZWrite、Blend、排序。
  • 后处理不对：先看 RenderTexture 格式、采样 UV、平台翻转、Pass 顺序。
  • 性能不对：先看 Draw Call、顶点、片元、带宽、Shader 复杂度，再决定优化。

参考资料

  • 原书：冯乐乐，《Unity Shader 入门精要》，人民邮电出版社，2016。
  • Unity Manual：Shaders、ShaderLab、Built-in Render Pipeline、URP、Shader Graph。
  • Unity Scripting API：Shader、Material、Graphics、RenderTexture。
  • 实时渲染经典：Real-Time Rendering、Physically Based Rendering（PBRT）。
  • GPU/图形学：RenderDoc、GPU Gems、GDC/Unite 分享。

现代 Unity 备注：这本书的代码是内置管线的“语法教材”，不是现代项目的模板。读完后，建议用 URP + Shader Graph 重做其中 2-3 个效果（例如 Blinn-Phong、法线贴图、边缘检测），再回来看内置管线代码，迁移会非常快。

本章要点：Shader 只是入口；继续学图形学、实时渲染、管线和工具；记住常用宏和迁移表；调试先分类再动手；用现代管线重做几个效果，比死记 API 更有效。
