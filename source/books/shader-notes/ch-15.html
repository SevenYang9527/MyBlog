非真实感渲染：卡通、描边与素描

原书第 14 章讲非真实感渲染（NPR）。它不追求物理正确，而是用风格化的光照、描边和纹理，做出卡通、素描、水彩等效果。核心手段是“把连续的光照量化成色阶”和“在轮廓处画线”。

卡通风格：色阶化光照

最简单的卡通光照是把 N·L 量化成几个台阶：

float NdotL = saturate(dot(N, L));
float toon = floor(NdotL * _Steps) / _Steps;
float3 diffuse = _LightColor0.rgb * _BaseColor.rgb * toon;

也可以用渐变纹理（Ramp）控制色阶，边缘更柔和、可调性更好。高光同样可以量化，或者用一张高光遮罩控制形状。

描边：反向外扩与边缘检测

方式做法特点
反向外扩（Inverted Hull）再画一遍模型，沿法线外扩，Cull Front，只显示背面轮廓。便宜、风格稳定；对硬边/法线不连续的模型可能断裂。
屏幕后处理边缘检测用深度/法线/颜色做 Sobel/Roberts。全屏统一，适合复杂场景；线宽受分辨率影响。
几何着色器/法线平滑复制模型并平滑法线后外扩。轮廓更连续，成本更高。
 
// 反向外扩 Pass（简化）
Pass
{
    Cull Front
    CGPROGRAM
    #pragma vertex vert
    #pragma fragment frag
    #include "UnityCG.cginc"

    float _OutlineWidth;
    fixed4 _OutlineColor;

    v2f vert (appdata v)
    {
        v2f o;
        float3 pos = v.vertex.xyz + v.normal * _OutlineWidth;
        o.pos = UnityObjectToClipPos(float4(pos, 1));
        return o;
    }

    fixed4 frag (v2f i) : SV_Target { return _OutlineColor; }
    ENDCG
}

素描风格

素描风格通常用噪声/纸张纹理 + 色调映射：根据光照强度选择不同的排线纹理，或者用噪声扰动 UV 做出手绘抖动。原书用一张噪声纹理和光照结果混合，模拟铅笔排线。

float3 sketch = tex2D(_SketchTex, i.uv * _Tile).rgb;
float tone = saturate(dot(N, L));
float3 color = lerp(_PaperColor, sketch, 1.0 - tone);

风格化的取舍

  • 不要追求物理正确：卡通光照可以故意压暗背光、强化轮廓。
  • 描边宽度要随距离/分辨率调整：否则远处太粗、近处太细。
  • 法线要连续：反向外扩依赖平滑法线；硬边模型要做法线平滑或改用后处理描边。
  • 阴影可以简化：卡通阴影常用硬阴影/色块，不必追求软阴影。

现代 Unity 备注：URP 可以用 Shader Graph 做色阶化光照和反向外扩；后处理描边可以用 Renderer Feature + 深度/法线。HDRP 的材质/光照模型更复杂，卡通渲染通常要自定义 Pass 或 Shader Graph。

本章要点：卡通 = 光照色阶化 + 描边；描边有反向外扩和后处理两条路；素描 = 噪声/排线 + 色调；风格化可以牺牲物理正确，但要保证轮廓、法线和分辨率下的稳定性。
