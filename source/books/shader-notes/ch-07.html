基础光照：从 Lambert 到 Blinn-Phong

原书第 6 章从“我们如何看到这个世界”讲起：光源、吸收与散射、着色、BRDF，然后落到 Unity 的标准光照模型：环境光 + 自发光 + 漫反射 + 高光反射。它分别实现了逐顶点和逐像素的 Lambert、Half-Lambert、Phong 和 Blinn-Phong。

标准光照模型

最终颜色 = 环境光 + 自发光 + 漫反射 + 高光反射
项作用常见实现
环境光 Ambient模拟全局间接光，避免背光全黑UNITY_LIGHTMODEL_AMBIENT 或自定义颜色
自发光 Emissive物体自身发出的光直接加一个颜色/纹理
漫反射 Diffuse粗糙表面的方向性反射Lambert / Half-Lambert
高光 Specular光滑表面的镜面反射Phong / Blinn-Phong

漫反射

Lambert 模型用 N·L 表示表面朝向和光照方向的一致性：

float3 N = normalize(worldNormal);
float3 L = normalize(_WorldSpaceLightPos0.xyz);
float NdotL = saturate(dot(N, L));
float3 diffuse = _LightColor0.rgb * _DiffuseColor.rgb * NdotL;

Half-Lambert 把 N·L 从 [-1,1] 映射到 [0,1]，让背光面也有渐变，常用于卡通/柔和风格：

float halfLambert = dot(N, L) * 0.5 + 0.5;
float3 diffuse = _LightColor0.rgb * _DiffuseColor.rgb * halfLambert;

高光反射

Phong 模型用反射方向 R 和视线 V 的点积：

float3 R = reflect(-L, N);
float spec = pow(saturate(dot(R, V)), _Gloss);
float3 specular = _LightColor0.rgb * _SpecularColor.rgb * spec;

Blinn-Phong 用半程向量 H = normalize(L + V)，少一次 reflect，高光形状略有不同，通常更便宜：

float3 H = normalize(L + V);
float spec = pow(saturate(dot(N, H)), _Gloss);
float3 specular = _LightColor0.rgb * _SpecularColor.rgb * spec;

逐顶点还是逐像素

方式计算位置优点缺点
逐顶点顶点着色器算光照，插值颜色便宜，适合低端设备/细分较多的模型高光/边缘容易失真，大三角形上尤其明显
逐像素片元着色器算光照高光细腻，效果稳定片元计算更贵

原书用“逐顶点/逐像素”的对比说明：光照模型一样，计算频率不同，结果和成本都不同。现代项目通常优先逐像素；移动端低端机可以用逐顶点或简化模型。

Unity 内置函数

内置管线提供了一些光照函数，例如 LightingLambert、LightingBlinnPhong，以及 _LightColor0、_WorldSpaceLightPos0、UNITY_LIGHTMODEL_AMBIENT。它们适合快速验证，但自定义效果通常手写更可控。

// 内置管线中常见的光照变量
float4 _LightColor0;              // 当前光源颜色
float4 _WorldSpaceLightPos0;      // 平行光方向或点光位置
float4 UNITY_LIGHTMODEL_AMBIENT;  // 环境光

一个逐像素 Blinn-Phong 的片元函数

fixed4 frag (v2f i) : SV_Target
{
    float3 N = normalize(i.worldNormal);
    float3 L = normalize(_WorldSpaceLightPos0.xyz);
    float3 V = normalize(_WorldSpaceCameraPos - i.worldPos);
    float3 H = normalize(L + V);

    float NdotL = saturate(dot(N, L));
    float NdotH = saturate(dot(N, H));

    float3 ambient = UNITY_LIGHTMODEL_AMBIENT.rgb * _DiffuseColor.rgb;
    float3 diffuse = _LightColor0.rgb * _DiffuseColor.rgb * NdotL;
    float3 specular = _LightColor0.rgb * _SpecularColor.rgb * pow(NdotH, _Gloss);

    return fixed4(ambient + diffuse + specular, 1.0);
}

现代 Unity 备注：URP 的光照宏、Light 结构、阴影/衰减函数与内置管线不同；_LightColor0 在 URP 中仍可能出现，但不能直接套用内置管线的 ForwardBase 写法。Shader Graph 里对应的是 Lighting 节点和 Custom Function。

本章要点：标准光照 = 环境 + 自发光 + 漫反射 + 高光；Lambert 用 N·L，Half-Lambert 做柔和过渡；Phong 用 R·V，Blinn-Phong 用 N·H；逐像素更细腻，逐顶点更便宜；内置函数适合验证，自定义效果手写更可控。
