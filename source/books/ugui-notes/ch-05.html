RectTransform：一个矩形，四个关键的归一化坐标

讲义第 7 到 12 页在讲 RectTransform。它列了组件里的几个东西：锚点、轴心、坐标值、旋转、缩放；又区分了 Blueprint 模式和 Raw Editor 模式；最后用“锚点形态”和“锚框形态”解释父物体变化时子物体怎么变。这部分是整份讲义里最值得保留的，因为它是后面所有布局和适配问题的根。

先把术语统一：

  • 锚点（Anchors）：两个归一化坐标 anchorMin 和 anchorMax，描述子矩形左下角和右上角“挂在父矩形里的百分比位置”。
  • 锚框（Anchor Rect）：由 anchorMin 和 anchorMax 在父矩形里围出来的矩形。两个点重合时，锚框退化成一条“锚点”。
  • 轴心（Pivot）：子矩形内部的归一化点，旋转和缩放围绕它进行，同时也是 rect 局部坐标的原点。
  • 尺寸（Size）：子矩形最终的宽高，由锚框尺寸和 sizeDelta 共同决定。
  • 位置（Anchored Position）：轴心相对“锚点参考点”的偏移。

锚点形态 vs 锚框形态

讲义用“锚点形态”和“锚框形态”区分两种情况，这个说法很形象：

形态条件父物体变大时尺寸由谁决定
锚点形态anchorMin == anchorMax子物体尺寸不变；位置跟着锚点移动，轴心到锚点的偏移保持不变。sizeDelta 就是实际尺寸。
锚框形态anchorMin != anchorMax子物体尺寸跟着锚框变化；可以用 Left/Right/Top/Bottom 或 sizeDelta 控制相对边距。实际尺寸 = 锚框尺寸 + sizeDelta。

讲义说“锚框的范围不能超过父类的矩形框”。这句话只在“用鼠标拖拽锚点”的默认编辑器行为下成立。Unity 的 RectTransform 编辑器里，按住快捷键（Editor 里的 EditorGUI.actionKey）或者直接在 Inspector 里输入数值，是可以把锚点设到父矩形之外的；代码里 anchorMin = new Vector2(-0.5f, 0f) 也不会被运行时阻止。它更像一条可读性约定，而不是引擎限制。

轴心：旋转中心，也是局部坐标原点

轴心是子矩形内部的归一化点。取 (0,0) 时在左下角，取 (1,1) 时在右上角，取 (0.5,0.5) 时在中心。它有两个作用：

  • 旋转和缩放围绕轴心进行。
  • RectTransform.rect 以轴心为局部坐标原点，所以 rect.x = -pivot.x * width，rect.y = -pivot.y * height。轴心在中心时，rect 的范围是 (-w/2, -h/2, w, h)。

讲义第 14 页说“轴心点就是 UI 元素旋转和缩放的基准点”，这是对的。第 7 页说 Raw Editor 模式下“pivot 会始终保持在 UI 内的相对位置，UI 跟随 pivot 的位置移动”，更准确的表述是：Raw Edit Mode 关闭了“改 pivot/anchor 时自动反向调整位置和尺寸以保持矩形不动”的行为；开启后，你改 pivot 或 anchor，矩形会跟着动。Blueprint 模式则是“忽略旋转和缩放来编辑矩形”，方便对齐。

锚点参考点：理解 anchoredPosition 的关键

当锚点分开时，anchoredPosition 并不是“到左下角锚点的偏移”，而是“轴心到锚点参考点的偏移”。锚点参考点由 anchorMin、anchorMax 和 pivot 共同决定：可以理解为在锚框里按 pivot 的比例取一个点。

// 概念上的锚点参考点（父矩形局部空间）
Vector2 anchorRef = new Vector2(
    Mathf.Lerp(anchorMin.x, anchorMax.x, pivot.x) * parentRect.width,
    Mathf.Lerp(anchorMin.y, anchorMax.y, pivot.y) * parentRect.height
);

// 轴心的位置 = 锚点参考点 + anchoredPosition
Vector2 pivotPos = anchorRef + anchoredPosition;

锚点重合时，锚点参考点就是那个锚点；锚点分开时，它是锚框里按 pivot 比例插值出来的点。讲义的“锚框里某一个点到 UI 轴心的矢量值”说的就是这个点，只是没有给它命名。

Left / Right / Top / Bottom 是什么

当锚点分开时，Inspector 会把 Pos 和 Width/Height 换成 Left、Right、Top、Bottom。它们表示子矩形四条边到对应锚框边的距离，可以理解成“锚框内部的 padding”。

这四个值对应代码里的 offsetMin 和 offsetMax：

offsetMin = anchoredPosition - Vector2.Scale(sizeDelta, pivot);
offsetMax = anchoredPosition + Vector2.Scale(sizeDelta, Vector2.one - pivot);

其中 offsetMin 对应左下角，offsetMax 对应右上角。设置 offsetMin / offsetMax 通常比直接改 sizeDelta 更直观，尤其是在四边拉伸的布局里。

考据结论：讲义对锚点、轴心、锚点形态/锚框形态的解释基本正确；需要修正“锚框不能超过父矩形”的绝对化表述，并补充“锚点参考点”的概念。Raw Edit Mode 的描述也应改成“关闭改 pivot/anchor 时的自动反向调整”。

一段打印 RectTransform 的代码

把下面这段挂在任意 UI 元素上，改一改父物体大小和锚点，观察输出，比看十张图都快：

using UnityEngine;

[RequireComponent(typeof(RectTransform))]
public class RectProbe : MonoBehaviour
{
    RectTransform rt;
    RectTransform parent;

    void Awake()
    {
        rt = GetComponent<RectTransform>();
        parent = rt.parent as RectTransform;
    }

    void OnGUI()
    {
        if (parent == null) return;

        GUILayout.Label($"parent rect: {parent.rect}");
        GUILayout.Label($"anchorMin: {rt.anchorMin}, anchorMax: {rt.anchorMax}");
        GUILayout.Label($"pivot: {rt.pivot}");
        GUILayout.Label($"anchoredPosition: {rt.anchoredPosition}");
        GUILayout.Label($"sizeDelta: {rt.sizeDelta}");
        GUILayout.Label($"rect: {rt.rect}");
        GUILayout.Label($"offsetMin: {rt.offsetMin}, offsetMax: {rt.offsetMax}");
    }
}

观察重点：改变父物体尺寸时，rect 怎么变；锚点重合和分开时，sizeDelta 的含义怎么变；改 pivot 时，rect 的 x/y 怎么变。

三个常见误区

  • 把 anchoredPosition 当成 localPosition：前者是相对锚点参考点的偏移，后者是相对父物体轴心的位置；两者在锚点不居中时完全不同。
  • 把 sizeDelta 当成尺寸：锚点重合时它才是尺寸；锚点分开时它是“尺寸差”。读尺寸请用 rect.size。
  • 用锚点做动画：改 anchorMin/Max、sizeDelta 会牵动布局和 Rebuild；位移动画优先改 anchoredPosition 或 Transform，缩放动画优先改 localScale。
