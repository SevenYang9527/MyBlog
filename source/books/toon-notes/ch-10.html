第 10 章 角色专项：头发、脸与那些不该描边的地方

同一个角色身上，头发、脸、眼睛、衣服的“光照规则”并不一样。原笔记在罪恶装备和原神两章里反复处理这三个地方：头发要高光沿发丝拉长，脸要阴影干净，眼睛和鼻子不能有描边。它们都不是靠一个全局参数解决的，而是靠单独的数据通道。

头发：沿切线拉长的高光

普通 Blinn-Phong 的高光是一个圆点，放在头发上会像塑料珠子。头发需要各向异性高光：用发丝切线 T 和半程向量 H 计算，让高光沿切线方向拉成一条带。Kajiya-Kay 的经典写法是 pow(sin(T,H), exp)，也可以直接用 1 - abs(T·H) 做近似。

float3 T = normalize(tangentWS);
float3 H = normalize(lightDirWS + viewDirWS);
float TdotH = dot(T, H);
float sinTH = sqrt(max(0.0, 1.0 - TdotH * TdotH));
float spec = pow(sinTH, _HairSpecPower) * _HairSpecMask;
float3 hairColor = baseColor + _HairSpecColor.rgb * spec;

原笔记里，罪恶装备的头发高光会乘 HairSpecularIntensityMask 和 BaseMap，再在暗部/亮部之间用 lerp 调强度；原神的头发则额外用 SpecularRange 和 ViewRange 两个遮罩，让高光在亮部出现、暗部保留一部分、背光时消失。这些遮罩不是“物理正确”，而是让头发看起来像动画里的高光带。

脸：编辑法线 vs SDF

罪恶装备和原神用了两条不同的路。罪恶装备在 DCC 里直接编辑脸部法线，让鼻子、颧骨、下巴的法线朝向更适合动画阴影；运行时用普通 N·L 就能得到比较干净的形状。原神则把阴影边界做成 SDF，运行时按光照角度采样，转头时阴影可以连续变化。

不该描边的地方

描边 Pass 是全局的，但眼睛、鼻子、嘴唇这些地方如果也描一圈，会立刻变成“黑线脸”。原笔记的做法是用顶点 Alpha 控制描边宽度：这些部位把 Alpha 设为 0，描边 Pass 乘上 v.color.a 就不会外扩。头发的发梢则可以让 Alpha 从 1 渐变到 0，描边自然收细。

// 头发高光：切线 + 遮罩
float3 hairSpec = pow(sinTH, _HairSpecPower) * _HairSpecMask * _HairSpecColor;

// 脸/发切换：顶点色 G 通道
float isFace = step(0.5, i.color.g);
float3 faceColor = lerp(shadowColor, baseColor, faceLight);
float3 finalColor = lerp(hairColor, faceColor, isFace);

// 描边：顶点 Alpha 为 0 的地方不扩
float outlineWidth = _OutlineWidth * i.color.a;
部位关键数据Unity 注意点
头发切线、发丝遮罩、高光范围切线要导入；透明发片控制 overdraw
脸（GG）编辑法线、顶点色 G导入时保留自定义法线
脸（原神）SDF、光照角、左右翻转转局部空间；SDF 不压 sRGB
眼睛/鼻子顶点 Alpha = 0Outline Pass 乘顶点 Alpha

Unity 视角：头发和眼睛是移动端 overdraw 的重灾区。头发尽量用 AlphaTest 或发片少叠几层，眼睛的高光尽量烘进贴图；描边 Pass 只画需要描边的 Layer，不要把透明发丝也一起外扩，否则会出现黑边和闪烁。

本章要点：头发用切线高光，脸用编辑法线或 SDF，眼睛/鼻子用顶点 Alpha 关描边。三者都是“局部规则”，不能指望一个全局阈值解决。
