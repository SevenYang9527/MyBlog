第 4 章 边缘光、视角光与暗部补光

边缘光和视角光经常被混为一谈，但它们看的不是同一个向量。边缘光看 N·V：法线越偏离视线，越靠近轮廓，越亮；视角光看 N·L：法线越朝向光源，越亮。原笔记把两者都做了“裁边”处理，并且指出：视角光本质上也可以理解成“从光源方向看的边缘光”。

裁边边缘光

连续边缘光用 pow(1 - N·V, exp) 就能做出来，但它会从轮廓往内慢慢衰减。卡通渲染通常用 step 把边缘光裁成一条窄带，再用 RimWidth 控制宽度，用遮罩控制哪些部位出现。

float rim = 1.0 - saturate(dot(normalWS, viewDirWS));
rim = step(1.0 - _RimWidth, rim) * _RimIntensity;
float3 color = baseColor + _RimColor.rgb * rim * _RimMask;

原笔记里还有一个更细的做法：把法线转到视角空间，只取 abs(N_VS.x) 作为左右轮廓的遮罩，这样边缘光只出现在脸的侧面，而不会在额头或下巴也亮一圈。这个做法在角色转头时特别有用。

暗部边缘光与亮暗分侧

如果整圈轮廓都亮，角色会像“发光塑料”。更自然的方式是：先算光源在亮部还是暗部，再决定边缘光用亮部色还是暗部色。原笔记给的逻辑是 RimDarkSide 和 RimBrightSide 分别做 lerp，最后相加；暗部那侧可以补一点冷色，亮部那侧补一点暖色。

屏幕空间的深度边缘光

原神在角色身上还用了后处理边缘光：单独渲染一张人物 Mask，再对深度图做邻域采样，深度差超过阈值的像素判为轮廓，最后只给 Mask 内的像素加边缘光。这样线宽按屏幕像素算，近处和远处更统一，也不会被角色自身的高模法线干扰。

// 后处理伪代码：深度差 + 人物 Mask
float rawDepth = SAMPLE_DEPTH_TEXTURE(_CameraDepthTexture, uv);
float center = LinearEyeDepth(rawDepth, _ZBufferParams);
float neighbor = LinearEyeDepth(
    SAMPLE_DEPTH_TEXTURE(_CameraDepthTexture, uv + _TexelSize.xy), _ZBufferParams);
float edge = step(_DepthThreshold, abs(center - neighbor));
float mask = SAMPLE_TEXTURE2D(_CharacterMask, sampler_CharacterMask, uv).r;
float rim = edge * mask * _RimIntensity;
return baseColor + _RimColor.rgb * rim;
类型公式适合注意
连续 Rimpow(1 - N·V, exp)头发、金属、柔光容易糊，宽度随视角变化
裁边 Rimstep(1 - width, 1 - N·V)赛璐璐角色要配遮罩，避免全轮廓发亮
暗部 Rim先算亮暗侧，再 lerp 颜色有明确主光的角色亮部/暗部宽度与颜色分开
屏幕空间 Rim深度差 + 人物 Mask统一线宽、后处理风格需要额外 Mask Pass 和深度图

Unity 视角：URP 里主 Pass 做 Rim 最便宜；后处理 Rim 需要 _CameraDepthTexture 和一张人物 Mask，通常由 RenderObjects Renderer Feature 把角色单独画到 RenderTexture。移动端如果已经有描边 Pass，优先把 Rim 放进主 Pass，少开一张全屏图。

本章要点：边缘光看 N·V，视角光看 N·L；裁边让边缘变成窄带；暗部/亮部要分侧调色；屏幕空间 Rim 适合统一线宽，但要额外 Mask 与深度采样。
