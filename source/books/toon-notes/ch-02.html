第 2 章 裁边漫反射：把 N·L 压成美术能改的色阶

传统的 Lambert 漫反射只有一条公式：N·L 越大越亮，越小越暗。它在写实渲染里很好用，但放在日式卡通里会显得“脏”：明暗交界线是一大片连续渐变，颜色被平均成灰，画面上没有手绘那种干净的块面。

原笔记的做法很直接：把 N·L 先映射到 0~1，再用 step 或 smoothstep 切成两档，最后在亮部色和暗部色之间插值。阈值决定交界线在哪，过渡宽度决定边缘是硬切还是稍微柔一点。

float NdotL = dot(normalWS, lightDirWS);
float halfLambert = NdotL * 0.5 + 0.5;
float shadow = smoothstep(_ShadowThreshold,
                          _ShadowThreshold + _ShadowSoftness,
                          halfLambert);
float3 color = lerp(_ShadowColor.rgb, _BaseColor.rgb, shadow);

Ramp：把色阶做成一张可画的贴图

step 只有两档，遇到需要三档、四档或者“暗部偏紫、亮部偏黄”的角色就不够用了。这时把 halfLambert 当作 U 坐标，去采样一张一维 Ramp 贴图：贴图从左到右就是暗到亮，美术可以直接在贴图上画颜色。

Ramp 贴图一般设成 Point 过滤，避免采样时把相邻色阶混在一起；如果使用 Linear 过滤，边缘会自然柔化，但也会失去“硬边”的味道。还要注意 sRGB 和项目颜色空间：Ramp 是颜色贴图就按 sRGB 导入，是纯数据遮罩就关掉 sRGB。

float2 rampUV = float2(halfLambert, 0.5);
float3 rampColor = SAMPLE_TEXTURE2D(_RampTex, sampler_RampTex, rampUV).rgb;
float3 color = rampColor * _BaseColor.rgb;

// 有些项目把 Ramp 偏移存在顶点色或 LightMap 里：
float u = saturate(halfLambert + _RampOffset);
float3 shifted = SAMPLE_TEXTURE2D(_RampTex, sampler_RampTex, float2(u, 0.5)).rgb;

为什么原笔记强调“裁边”

四个项目用了不同的数据，但思路一致：罪恶装备把材质类型和偏移塞进 LightMap，碧蓝幻想用 BaseMap 乘阴影色，原神把 10 层 Ramp 排成一张图，战双则把 PBR 和 NPR 混在一起。它们都不是“算一个更真实的漫反射”，而是“把漫反射压成美术能理解的几块”。

做法效果成本 / 注意点
Step最干净的硬边，适合赛璐璐阈值一动，画面变化很大；过渡完全消失
SmoothStep交界处留一点柔化，避免锯齿感过渡宽度要克制，太宽会回到 Lambert
Ramp LUT多档颜色、可画渐变、可加色相偏移多一张贴图；过滤模式和 sRGB 要设对
LightMap 偏移同一套 Shader 适配不同部件需要美术在贴图/顶点色里写数据

Unity 视角：URP 里主光方向可以从 GetMainLight() 拿，阴影坐标用 GetShadowCoord()。如果你只想用主光做色阶，副光只做环境提亮，就不要让副光参与同一个 step，否则阈值会被多光源搅乱。Ramp 贴图的 Import Settings 里把 Wrap Mode 设为 Clamp，Filter Mode 按风格选 Point 或 Bilinear。

本章要点：裁边漫反射不是“取消光照”，而是把连续光照压成几档；Step 最硬、SmoothStep 最稳、Ramp 最可画；阈值、过渡宽度、RampOffset 是三个最值得做成参数的量。
