第 9 章 战双帕弥什：PBR 与 NPR 混着用

《战双帕弥什》的底子仍然接近罪恶装备：裁边漫反射、LightMap、顶点色、描边。但它多了一层 PBR：金属、皮革、机能面料需要真实的高光形状和粗糙度变化，纯卡通高光不够用。于是它把 PBR 的 Metalness、Smoothness、AO 和 NPR 的 Ramp、Rim、描边放在同一套 Shader 里，用一张 PBRMask 决定“这块像素走哪条路”。

混合光照：先算 NPR，再按遮罩叠 PBR 高光

最常见的做法是：漫反射仍然用裁边 Ramp，高光则根据 PBRMask 在“卡通高光”和“PBR 高光”之间插值。这样衣服、皮肤保持干净的块面，金属扣、武器、机械件又能有真实的高光形状。代价是同一个片元里要算两条高光路径，移动端需要控制面积和分支。

float pbrMask = SAMPLE_TEXTURE2D(_PBRMixMap, sampler_PBRMixMap, uv).a;
float metallic = SAMPLE_TEXTURE2D(_PBRMixMap, sampler_PBRMixMap, uv).r;
float smoothness = SAMPLE_TEXTURE2D(_PBRMixMap, sampler_PBRMixMap, uv).g;

float3 nprSpec = ToonSpecular(N, L, V) * _ToonSpecColor;
float3 pbrSpec = GGXSpecular(N, L, V, smoothness, metallic) * _PbrSpecColor;
float3 spec = lerp(nprSpec, pbrSpec, pbrMask);
float3 color = nprDiffuse + spec;

头发高光：GGX 与 BlinnPhong 的切换

原笔记提到战双的头发高光可以在 GGX 和 BlinnPhong 之间切换，用 _SpecShift 这类关键字控制。GGX 的高光更“物理”，边缘更长；BlinnPhong 更干净，适合卡通发片。两种都保留，是因为不同角色/不同发型的风格需求不一样。

#ifdef _SPEC_SHIFT_GGX
    float3 hairSpec = StylizedSpecularLight_GGX(
        N, L, V, roughness, metallic) * _HairSpecColor;
#else
    float3 hairSpec = StylizedSpecularLight_BlinnPhong(
        N, L, V) * _HairSpecColor;
#endif

float3 hairColor = baseColor * _HairShadowColor
                 + hairSpec * _HairSpecIntensity * specMask;

代价：每个角色一套 Shader

原笔记很坦诚地指出：战双的渲染特性太多，几乎每个角色都有自己的 Shader，导致多人协作不方便。这是“风格自由”的代价。对 Unity 项目来说，更稳的路线是做一个可配置的 UberShader，把常用特性做成关键字/位掩码，把真正特殊的角色单独开分支；同时用材质变体收集和 Shader 变体剥离控制包体。

通道 / 参数战双里的用途Unity 落地
PBRMixMap.rMetallic金属度，决定高光颜色与反射
PBRMixMap.gSmoothness1 - 粗糙度，控制高光大小
PBRMixMap.bAO / 高光遮罩压暗缝隙、限制高光
PBRMixMap.aPBRMaskNPR/PBR 混合权重
LightMap.rRampOffset加到 halfLambert
LightMap.gShadowAO常暗区域
LightMap.b高光类型裁边 / BlinnPhong / PBR

Unity 视角：PBR 和 NPR 混用时，最容易忽略的是颜色空间和金属度。金属的高光颜色应该来自 BaseColor（或明确的 SpecColor），非金属的高光才是白色；如果直接把 PBR 高光叠在卡通色上，金属会发灰。移动端可以把 GGX 简化成 BlinnPhong 或预积分高光，但要让美术知道“简化后形状会变”。

本章要点：战双的路线是“NPR 打底 + PBR 补材质”：PBRMask 控制混合，PBRMixMap 存金属度/光滑度/AO，头发高光可在 GGX 与 BlinnPhong 间切换。自由度高，但工程上要控制 Shader 数量。
