第 3 章 裁边高光：从一团白到可控形状

写实渲染里的高光是一块连续衰减的亮斑，日式卡通里通常不要这种“糊成一片”的高光。原笔记先给出 Blinn-Phong：pow(N·H, exp)，然后用 step 把高光截断，再用一张高光遮罩控制它出现在哪里。

float3 H = normalize(lightDirWS + viewDirWS);
float spec = pow(saturate(dot(normalWS, H)), _SpecPower);
spec = step(_SpecThreshold, spec) * _SpecMask;
float3 color = baseColor + _SpecColor.rgb * spec;

“高光变形”是什么

原笔记在讲完 StepSpecular 之后，专门放了一页“高光形变”：一个球上不是圆形高光，而是两块被拉长、切角的白斑。这意味着高光不只是亮不亮，还可以有形状。做法通常有三种：

  • 用 Ramp 或遮罩把 N·H 的等值线画成想要的形状；
  • 用 MatCap：在视角空间里拿 N 的 XY 去采样一张“已经打好光的球”，高光形状由贴图决定；
  • 用各向异性高光，沿头发或布料的切线方向拉长。

四个项目怎么用高光

罪恶装备把高光类型塞进 LightMap 的 B 通道：0 表示无高光，小于 128 是裁边高光，大于 128 是 BlinnPhong 高光；皮革、金属还会再走单独的裁边高光分支。碧蓝幻想把高光类型做成材质层的一部分，并额外提供 StepNV、StepNL、StepNH 等边缘光/高光变体。原神用 LightMap.a 选 Ramp 层，用 LightMap.r 选高光类型，用 LightMap.b 控高光强度，再用 MatCap 做视角光。战双则在 PBRMixMap 里区分金属度、光滑度和 PBR 遮罩，高光可以在 GGX 与 BlinnPhong 之间切换。

项目高光数据典型用途
罪恶装备LightMap.b：0 / <128 / >128无高光、裁边高光、BlinnPhong 高光
碧蓝幻想LayerMap + 每层参数按材质层决定高光/边缘光类型
原神LightMap.a / r / b + MatCapRamp 层、高光类型、高光强度、视角光
战双PBRMixMap + SpecularMaskPBR 高光与卡通高光混用
 
// MatCap：用视角空间法线的 XY 采样一张球形光照图
float3 normalVS = mul((float3x3)UNITY_MATRIX_V, normalWS);
float2 matcapUV = normalVS.xy * 0.5 + 0.5;
float3 matcap = SAMPLE_TEXTURE2D(_MatCapTex, sampler_MatCapTex, matcapUV).rgb;

// 用遮罩决定谁有高光，避免整件衣服都闪
float3 finalColor = baseColor + matcap * _MatCapIntensity * specMask;

Unity 视角：高光遮罩最好和粗糙度/金属度分开画。日式卡通里“哪里该闪”是美术决定，不是物理推导。移动端可以把高光形状直接烘进 MatCap 或 Ramp，运行时只做一次采样；多光源场景里，卡通高光通常只跟主光，副光最多给一点环境反射。

本章要点：卡通高光 = 强度计算 + 阈值截断 + 形状控制。Step 负责“干净”，MatCap/遮罩负责“形状”，切线负责“拉长”。不要把所有材质都套同一个高光公式。
