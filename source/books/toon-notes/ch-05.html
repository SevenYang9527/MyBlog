第 5 章 描边：Cull Front、平滑法线与顶点 Alpha

日式卡通描边最常用的还是“反向外扩”：把模型再画一遍，沿法线方向往外推一点，然后 Cull Front 只显示背面。正面被正常模型挡住，剩下的外圈就是描边。它便宜、稳定、风格统一，缺点是硬边模型会裂开，线宽也会随距离变化。

硬边为什么会裂

如果模型是硬边（同一个位置有多个法线），沿各自法线外扩就会在拐角处分开，描边出现缺口。解决办法不是把模型改成全平滑，而是单独维护一套“描边法线”：按顶点位置合并法线，再写回切线或顶点色，描边 Pass 用这套法线，正常光照仍然用原法线。

// 把平滑后的法线写进 tangent.xyz，供 Outline Pass 使用
static void WriteSmoothNormalToTangent(Mesh mesh)
{
    var sum = new Dictionary<Vector3, Vector3>();
    for (int i = 0; i < mesh.vertexCount; i++)
    {
        Vector3 p = mesh.vertices[i];
        Vector3 n = mesh.normals[i];
        sum[p] = sum.TryGetValue(p, out var acc) ? acc + n : n;
    }

    var tangents = new Vector4[mesh.vertexCount];
    for (int i = 0; i < mesh.vertexCount; i++)
    {
        Vector3 n = sum[mesh.vertices[i]].normalized;
        tangents[i] = new Vector4(n.x, n.y, n.z, 0);
    }
    mesh.tangents = tangents;
}

顶点 Alpha 控制宽度

原笔记里描边宽度不是全局常数，而是乘了顶点色的 Alpha：眼睛、鼻子这些不需要描边的地方把 Alpha 设为 0；头发发梢可以让 Alpha 从 1 渐变到 0，描边就会自然收细。这样不用给每个部件单独做一套材质。

// Outline Pass：v.tangent.xyz 是平滑法线，v.color.a 是宽度遮罩
v2f vert (Attributes v)
{
    v2f o;
    float width = _OutlineWidth * 0.01 * v.color.a;
    v.vertex.xyz += v.tangent.xyz * width;
    o.positionCS = TransformObjectToHClip(v.vertex.xyz);
    return o;
}

后处理描边与屏幕空间宽度

如果场景里角色很多、硬边很复杂，后处理描边更省事：用深度、法线或颜色做边缘检测，再乘一张人物 Mask。它的线宽按像素算，近处远处一致，但需要额外的深度/法线纹理，并且对细小结构（发丝、睫毛）容易断线。原笔记主要讲反向外扩，后处理作为对照即可。

方案优点缺点适合
反向外扩便宜、风格稳定、可控硬边裂缝、线宽随距离变化角色特写、卡通项目
后处理深度/法线线宽统一、适合多角色额外纹理、细结构易断大场景、统一描边
顶点 Alpha 外扩不用拆材质，能局部关描边需要美术写顶点色眼、鼻、发梢

Unity 视角：Outline 可以写在同一个 Shader 的第二个 Pass，也可以用 RenderObjects Renderer Feature 单独画一层。写进同一个 Shader 更省状态切换，但要注意 DepthOnly、ShadowCaster 不要被描边 Pass 污染；用 Renderer Feature 则更容易按 Layer 控制。无论哪种，外扩距离最好在裁剪空间或屏幕空间换算，避免角色走近时描边突然变粗。

本章要点：反向外扩是主力方案；硬边要单独存平滑法线；顶点 Alpha 控制局部宽度；线宽要按距离/FOV 换算；后处理描边是另一种工程取舍。
